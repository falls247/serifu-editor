# Serifu Editor

複数画像にセリフ・漫画風効果音・吹き出し・キャプションを配置するWebアプリ。左に元画像、中央にセリフ編集、右に位置調整付きプレビューを表示。画像ごとの3列が縦に並び、スクロールしながら連続編集できる。画像は外部送信せず、ブラウザ内で処理する。

公開版: https://falls247.github.io/serifu-editor/

ローカル開発を引き継ぐ場合は、[開発ドキュメント](dev/docs/README.md)の引継書とADRを参照。

## 編集

1. 「フォルダを開く」または「画像を追加」で複数画像を読み込む。画像名の数字順で並ぶ。
2. 各画像の中央で「＋ 男性」「＋ 女性」「✦ 効果音」を追加し、セリフを直接入力。入力欄は1行から始まり、改行数に合わせて自動で伸縮する。長い1行は横スクロールし、入力欄の自動折返しは行わない。
3. 男性セリフは黒、女性セリフはピンク。白い縁取りを必ず付ける。途中でも話者を切替できる。吹き出しは自動追加せず、必要な画像だけ「○ 吹き出し」で追加する。
4. 効果音の漫画エフェクトを選ぶ。「立体」は黒い立体影と傾き、「集中線」は放射線、「スピード」は流線、「震え」は文字ごとの角度・上下変化と震え線。効果音の文字色も変更できる。
5. 右のプレビューで文字をドラッグして移動。選択枠の右下の角でサイズ、上の丸で回転を調整。下の設定では元画像のピクセル単位でX/Y、文字サイズ、文字自体の太さ、回転、配置幅・高さ、白縁の太さ、縦書きを修正できる。
6. カード見出しの「男性セリフ」「女性セリフ」の右横で「男性・黒」「女性・ピンク」を切替。複製、削除、前後関係、画像別Undo/Redoに対応。
7. 下へスクロールして次の画像を編集。「編集完了・次へ」は確認済みにして次へ移動。「文字を次の画像へ複製」は画像サイズに合わせて配置を拡縮し、次の画像の既存文字に追加する。
8. コピー元の画像で「文字を一括コピー」、貼付け先の画像で「文字を一括ペースト」を押すと、台詞・効果音・吹き出し・キャプションをすべて追加する。「文字を一括カット」は、同じ内容を保持して元画像の文字をすべて取り除く。書体・色・太さ・エフェクト・重なり順を引き継ぐ。横長から縦長への貼付けにも対応し、X・配置幅は横倍率、Y・配置高さは縦倍率、文字サイズ・太さは両倍率の小さい方で拡縮する。縦横比が変わると改行や収まりが変わるため、プレビューで位置調整できる。コピー元を後から編集・削除しても保持した内容を複数画像へ繰り返し貼付けできる。「戻す」でカット一回分または貼付け一回分をまとめて取り消せる。取り消しはそれぞれ操作した画像で行う。コピー・カットの内容はページを再読込するまで保持。プレビューで選択中の文字をコピーするショートカットとは別に使える。
9. 「一括保存」で保存先の親フォルダを選ぶ。その中に日時とランダムID付きの新規フォルダを作り、全画像を元解像度のPNGと再編集用データに保存。保存形式に応じて `serifu-project.serifu` または `serifu-project.json` を添える。保存先選択APIが使えない環境では、同じ内容をZIPとしてダウンロードする。選択枠は出力しない。連番で同名の衝突を防ぐ。
10. 右隣の「編集済み画像一括保存」は、編集済みの画像だけを新規フォルダまたはZIPへ保存する。画像を開いただけ、選択しただけ、「編集完了・次へ」を押しただけの画像は除外。台詞・効果音・吹き出し・キャプションの追加・変更・削除・カット・貼付けが編集対象。最初の編集をUndoで戻せば未編集に戻り、保存済みの文字を含む従来JSONの読込は編集済みとして扱う。高速形式は保存時の判定を保持する。編集済みの判定は編集データ・一時保存にも保持する。保存する編集データにも選ばれた画像だけを含める。
11. 各画像のLIVE PREVIEW右側、「戻す」の左にある「画像を保存」は、その画像だけを元解像度のPNGでダウンロードする。台詞・効果音・吹き出しを合成し、選択枠は含めない。未編集の画像も単体保存できる。保存先はブラウザのダウンロード設定に従い、フォルダ保存APIがないブラウザでも利用可能。書体の読込完了を待って書き出す。再編集用の情報は「編集データを保存」または「一時保存」で別途保持する。

## 吹き出し

- 男性・女性・効果音の右隣にある「○ 吹き出し」で、文字から独立した楕円レイヤーを追加する。初期状態は白色、25%透過（不透明度75%）、細い黒の輪郭線、テールなし。楕円は右上の画像端からはみ出す位置に配置し、画像境界で切り取って表示・出力する。
- カードで塗り色・透過率・枠線の色・枠線の太さを変更。吹き出しを選ぶと、右の位置調整にも「枠線の色」「枠線の太さ」を表示し、カードと連動する。枠線の色はテールにも適用し、Undo/Redo、コピー、編集データ、一時保存、PNGに保持する。枠線の太さを0にすると枠線を消せる。右の位置調整でX/Y、配置幅・高さ、回転を変更できる。楕円の中心を画像外へ置くことも可能。ドラッグで移動、右下の角で楕円の幅・高さを調整する。
- 吹き出しは追加順や前後操作に関係なく、常にすべての台詞より下。効果音との関係は「効果音の下／上」で切替。「効果音の上」では効果音→吹き出し→台詞の順で描画する。右側の「効果音の下へ／上へ」ボタンでも変更できる。
- 「テールを追加」をONにすると、水色の先端をドラッグして位置を調整できる。右側の数値でも先端X/Y、付根の角度、付根の幅を変更可能。先端X/Yは回転前の楕円の中心からの距離。ドラッグでは付根の角度も先端の方向に追従する。テールと楕円は一つの面として塗るため、接続部分だけ透過率が濃くならない。
- 吹き出しも複製・削除・Undo/Redo、プレビューのコピー・ペースト、画像単位の一括コピー・カット・ペースト、PNG書出し、編集データ、一時保存に対応する。別解像度へ貼付けると楕円とテールの位置・大きさを拡縮する。

## キャプション（モノローグ・説明）

- 「○ 吹き出し」の右隣にある「▭ キャプション」で、本文と長方形のボックスを一つのレイヤーとして追加する。画像を開いただけでは追加しない。初期値は白い背景を25%透過（不透明度75%）、黒い枠線、黒い文字、縦書き。本文と枠線は不透明で描く。
- 中央のカードで本文、文字色、背景色、背景の透過率、枠線の色・太さ、内側の余白を編集する。本文欄は1行から始まり、入力した改行数に合わせて高さを変える。右側では書体、縦書き／横書き、文字サイズ、位置、ボックスの幅・高さ・回転を調整できる。プレビューのドラッグ、右下の角、上の丸でも移動・サイズ変更・回転できる。
- 新規キャプションの本文は左右・上下とも中央揃え。「左右の揃え方」で左／中央／右、「上下の揃え方」で上／中央／下を独立指定する。中央カードと右側の設定は連動し、縦書き・横書き、自動追従ON/OFFのいずれでも使える。横書きでは各行を左右に、縦書きでは各列を上下に揃える。配置設定はコピー・Undo/Redo・PNG・編集データ・一時保存に保持する。旧version 5のキャプションで配置設定がない場合は、従来の右・上揃えを保って読み込む。
- 「文字サイズをボックスに合わせる」は初期OFF。OFFでは手動の文字サイズを保ち、ボックスを広げたり縮めたりしても文字サイズは変えない。本文はボックス内で折り返し、収まらない部分は内側の領域で切り取る。
- 自動追従をONにすると、本文・改行・書体・文字方向・ボックス寸法・余白・枠線の太さから、本文が収まる最大の文字サイズを0.5px単位で選ぶ。縦書きは上から下、右から左へ、横書きは左から右、上から下へ折り返す。手動の文字サイズは記憶しておき、OFFに戻すと再使用する。「表示文字サイズ」で現在の描画サイズを確認できる。
- 自動追従の範囲は1〜500px。極端に小さいボックスや長い本文で最小サイズでも収まらない場合は、設定欄に表示する。ボックスを広げるか本文・余白を減らして調整する。
- キャプションも複製・削除、Undo/Redo、プレビューのコピー／ペースト、画像単位の一括コピー／カット／ペースト、単体・一括PNG保存、編集データ、一時保存・自動保存に対応する。別解像度へ貼付けるとX・幅は横倍率、Y・高さは縦倍率、手動文字サイズ・余白・枠線の太さは両倍率の小さい方で拡縮し、自動追従モードと各色を保持する。
- 吹き出しはキャプションより下に描画する。キャプション同士や台詞との順序は「背面へ／前面へ」で調整できる。「効果音の上」の吹き出しがある場合は、効果音→吹き出し→台詞・キャプションの順で描画する。

## 縦書き・エフェクト・プリセット

セリフ・効果音の新規追加は縦書きが既定。縦書きの「、」「。」などの句読点は、書体の実際の描画範囲を測って文字枠の右上に配置する。台詞の太さを変えた場合も同じ配置を保ち、横書きでは書体本来の位置を使う。効果音とキャプションにも同じ句読点配置を適用する。効果音には極太のDela Gothic Oneと、細いハネ・払いを持つYuji Bokuの筆文字書体を用意する。プリセット「縦書き・感情／緊張の掠れ」「縦書き・強い縦ブラー」から始め、「ブラー・掠れ・ハネ・歪みの調整」で強さを変えられる。

セリフや効果音を選び、右側の「書体」で21種類から変更できる。新しい書体は初めて選んだ時にサイトから読み込み、読込完了後にプレビューを更新する。PNG保存は使用する書体の読込完了を待つ。書体と文字の太さの選択もプリセット・編集データ・一時保存に記憶する。

「激筆 SFX」は添付フォントを同梱。右側の「書体」→「漫画の筆文字・効果音」→「激筆 SFX（GEKIFUDE SFX）」で選ぶ。かな・英大文字・数字・記号向けで、漢字と英小文字は未収録のため端末の代替書体で表示する。作者HIDEOUT、CC0 1.0。配布物のチェックサムを確認して組み込み、CC0ライセンスを同梱する。

「漫画エフェクト」の「なし」は集中線・震え・立体影を付けない。「先細り」は入力順に文字サイズを減らし、縦書き・横書きの両方に対応する。変化率は初期10%、0〜100%を0.5刻みで数値指定。基準文字サイズ100px、10%なら100→90→80→70pxと、毎文字、基準サイズの10%ずつ縮小する。最小8pxで止め、改行・自動折り返しでも縮小の順番は継続する。字間と折り返しも各文字のサイズに合わせる。サイズのばらつきを0にすると指定の変化率どおりになり、ばらつき・左右のズレとも併用できる。ブラー・掠れ・歪みは独立したパラメータとして保持する。先細りの変化率はプリセット・コピー・編集データ・一時保存にも保存する。

「文字の太さ（px）」は−10〜30、0.5刻みで指定。0は書体の標準、正の値は太く、負の値は細くする。文字サイズ・配置幅・白縁の太さは変えず、文字のインク部分を拡張／縮小するため、固定ウェイトの書体にも適用できる。大きく細くすると細い線が消える場合がある。書体にない文字は端末の代替書体で表示する。

プレビューで文字を選択して **Ctrl＋C／⌘＋C**、貼付け先のプレビューをクリックして **Ctrl＋V／⌘＋V**。文字内容、男女の区分、書体、太さ、エフェクト、配置をコピーする。別解像度の画像にはサイズと座標を合わせ、貼付けごとに20pxずつずらす。貼付け後は選択状態になり、ドラッグやUndo/Redoで修正できる。コピー後に元の文字を編集してもコピー内容は保持する。アプリ内の同じタブで使うコピー機能で、入力欄では通常の文字のコピー・貼付けが働く。

- 縦ブラー0〜300px・横ブラー0〜150pxを独立指定。文字を傾けてもブラーは配置枠の縦・横方向を保つ。全体の回転に合わせて方向も回転する。
- 滲みの強さ0〜400%と、元の文字の芯0〜100%を別指定。強い滲みと判読性を両立できる。
- 輪郭の荒れ、筆の掠れ、ハネ・払いはそれぞれ0〜100%。文字の実際の輪郭を削り、筆の繊維のような細い先端を伸ばす。掠れは入力文字から固定生成し、再描画・PNG保存・復元で変わらない。
- 「文字のばらつき・ブラー・掠れ・歪みの調整」に手描きのばらつきを追加。「文字サイズのばらつき」は0〜30%で、各文字の大きさを基準サイズの±指定%以内で変える。「左右のズレ」は0〜20%で、基準の文字幅（文字サイズ×横倍率）の±指定%以内で各文字を左右にずらす。どちらも0.5刻み。標準の効果音設定はサイズ差5%・左右3%。縦書き・横書きの両方で使える。
- 文字ごとのばらつきは固定パターンとして編集データ・一時保存に保持し、再描画・PNG保存・再読込で変えない。コピーも同じパターンを保持する。プリセットにはばらつきの強さを記憶し、新規の文字にはそれぞれのパターンを付ける。0を指定すると追加のばらつきがなくなる。旧データ・旧カスタムプリセットで未指定の場合は0として読み込む。
- 流れる残像は最大300px。残像の方向、全方向ブラー、波打ち／膨張／先細り、傾き、縦横倍率も調整できる。
- 強い設定は文字の判読性を下げる。極端に大きい文字・倍率・ブラーでは内部描画の解像度を制限し、メモリの過剰確保を防ぐ。PNG自体は元画像の解像度で出力する。

台詞・効果音・吹き出し・キャプションの各カードの「保存」または「選択中の設定を記憶」で名前を付け、書式と配置をプリセットに保存する。本文・話者は含めない。カードの選択欄で適用し、種類ごとの新規追加の既定にもなる。同じ種類・同じ名前は確認後に上書き。カードの「削除」または上部の既定選択の右の「×」で、確認後にユーザープリセットを削除できる。配置済みのオブジェクトは保持し、組込みプリセットは削除不可。配置・文字サイズ・ブラー等は画像解像度に合わせて拡縮する。プリセットは同じブラウザに記憶し、編集データにも同梱する。

## 一時保存・自動保存

- 「一時保存」は元画像、編集情報と設定を同じブラウザのIndexedDBへ保存する。ファイル選択やダウンロードは不要。
- 自動保存は既定でON、2分周期。0.1〜1440分（6秒〜24時間）へ変更できる。変更がない場合は書き込まない。
- 再読込後は「保存した編集を復元」で前回の一覧に戻れる。編集中の一覧がある場合は置換前に確認する。
- 保存は画像と編集情報を一つのトランザクションで更新する。保存が失敗しても前回の保存を保持する。空き容量不足等は画面に表示する。
- 保存中の追加入力は次の周期で保存する。保存後の変更がある場合は状態表示に明示する。
- 一時保存は最新1件。同じブラウザの別タブで保存すると最新内容に置き換わる。別ブラウザ・別端末には引き継がれず、サイトデータ削除で消える。保管・持ち出しには「編集データを保存」を使用する。
- 復元後は元フォルダへ直接接続していないため、元画像削除は無効。

## 一括処理の進捗

表示設定の直下で、操作名・現在の段階・件数・失敗件数・経過時間を確認できる。「中断」で残りの処理を止める。画像追加中は準備済みページを編集でき、表示範囲も切り替えられる。ページの追加・削除・順序変更や保存は読込終了後に行う。

中断した画像追加では採用済みページを残す。PNG保存では完了済みファイルを残し、フォルダと保存枚数を表示する。通常ダウンロードは開始後にアプリから取消できない。完了・中断・失敗時には進捗欄を閉じ、結果を画面下部へ表示する。ZIP作成はダウンロード開始前まで中断でき、中断したZIPは出力しない。

## 編集データ・元画像

「編集データを保存」は画像、男女の区分、効果音スタイルと先細りの変化率、文字と位置、吹き出しの楕円・透過・テール・重なり、キャプションの本文・色・書体・ボックス・自動追従モード・配置方向、編集済みの判定を1ファイルに含める。「編集データを読込」で現在の一覧に追加し、再編集できる。初期保存形式は、元画像をBase64化せず収録する高速形式 `.serifu`。以前の版へ渡す場合は「保存形式」で従来形式 `.json` を選ぶ。一括PNGに添える編集データもこの選択に従う。高速形式はコンテナ版1、内部の編集データはversion 6。従来JSONもversion 6で出力する。version 1〜5の読込と、version 3〜5の一時保存の復元にも対応する。旧version 1の文字付き吹き出しは、テキストと位置を保って白縁の男性セリフに変換する。旧吹き出しの形状・しっぽは引き継がない。

- 編集は元画像を上書きしない。
- 「一覧から外す」は元ファイルを残す。未保存の当該画像の編集は失われる。
- 「元画像を削除」は、ファイル名を確認後、**実ファイルを完全削除**。ゴミ箱には移動しない。Undoでは復元できない。
- 元画像削除は「フォルダを開く」で直接接続した画像のみ。画像追加、サンプル、編集データからの画像には無効。
- 保存途中の失敗は保存済み枚数と出力フォルダを表示。部分出力は残る。
- ブラウザを閉じる前に一時保存または書き出しを確認する。自動保存周期の途中の変更は未保存。

## 起動・公開

Node.js 22以降を用意して実行。アプリ本体に依存パッケージは不要。

```bash
npm start
```

http://localhost:5173 を開く。Windowsから直接起動、またはWSLから起動してWindowsブラウザのlocalhostから利用できる。画像の選択はブラウザ側のファイルシステムで行う。

ローカルで公開版と同じ書体を用意する場合、初回に `npm run fonts` を実行する。公開時はCIで準備する。未準備時は端末の日本語書体を使用する。17種類の書体とそれぞれのOFLライセンスは[Google Fonts](https://github.com/google/fonts/tree/7085eb89a950e85db5b166b7a58d414544b4140c/ofl)の固定バージョンから取得し、チェックサムで検証する。激筆 SFXと851チカラヨワクはリポジトリ内の `assets/font-sources/` から復元またはコピーし、フォントと各作者の規約のチェックサムを検証する。計19種類の同梱書体と端末の2種類を使用し、同梱書体は公開サイト自身から配信する。

GitHub Pagesは **Settings → Pages → Source → GitHub Actions** を設定。mainへのpushでチェック・テスト・ビルドを通過した版を自動公開する。Actionsの **Deploy GitHub Pages → Run workflow** からも実行できる。

```bash
npm run build
```

`_site/` へ公開用HTML/CSS/JavaScript、書体とライセンスを出力する。公開先にNode.jsサーバーは不要。

## 対応・制約

- 新規フォルダへの直接一括保存・元画像削除には File System Access API が必要。PC版Chrome / Edgeと、localhostまたはHTTPSが対象。
- 非対応ブラウザでも複数ファイル・フォルダからの読込、編集、画像単体のPNG保存、編集データ保存を利用できる。保存先選択APIが使えない環境の一括保存は、PNGと編集データをZIPへまとめてダウンロードする。元ファイル削除は無効。ZIPは全体4GiB未満・最大65535ファイルで、作成中は出力Blobを保持する。
- デスクトップ・iPad横向きでは3列。狭い画面では元画像／セリフ／プレビューを順番に並べる。
- PNG出力。GIFは静止画として扱う。EXIF等のメタデータは引き継がない。基本のゴシック・明朝と代替書体は端末環境に依存。
- 縦書きは文字単位配置。高度な縦組み約物・ルビには未対応。長文が配置高さを超える場合は文字サイズか配置幅・高さを調整する。
- プレビューは最大1400pxの縮小表示で、出力は元解像度。大量・高解像度画像はメモリ使用量が大きくなるため分割編集を推奨。
- プレビューでCtrl/Cmd+C・V: 選択した文字のコピー・貼付け。矢印キー: 1px移動、Shift+矢印: 10px、Ctrl/Cmd+Z: 戻す、Shift追加: やり直す。

## かすれ印刷の効果音と吹き出し装飾（2026-10-10）

効果音レイヤーの「インク質感」から「かすれ印刷・荒れインク」を選択。強さ・擦れ筋の長さ・方向・飛沫量を設定できる。組み込み「かすれ印刷・荒れインク（参考画像風）」プリセットで開始可能。欠けは白い塗りではなく**透明**なので、元画像がそのまま見える。擦れ筋角度90°は字形内の下方向。従来の「筆の掠れ」と併用可能。「模様を再生成」を選ぶと1回分のUndo対象となり、以後は固定seedで同じ模様を再描画する。

吹き出しレイヤーでは「影を付ける」をオンにすると、影色・濃さ・ぼかし・X/Yのずれを調整できる。「枠線の描き方」で「ブラシ風」を選ぶと、荒れ率と枠線太さに応じてラフな縁取りを描画する。「尖り形」の尖り度を増しても、中央のセリフを収めるために本文描画幅・高さを内側へ制限する。枠線・テールは従来どおり使用可能。

編集データはモデル版**7**で保存。旧JSON v1～v6と旧高速 `.serifu` v6を読み込める。新しいv7形式を旧アプリで開くことは避ける。描画はPNG書き出しも同じパイプラインで処理する。

設計と検証上の注意は `dev/docs/adr/0012-distressed-ink-and-balloon-effects.md` を参照。
