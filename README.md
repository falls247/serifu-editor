# Serifu Editor

複数画像にセリフ・漫画風効果音を配置するWebアプリ。左に元画像、中央にセリフ編集、右に位置調整付きプレビューを表示。画像ごとの3列が縦に並び、スクロールしながら連続編集できる。画像は外部送信せず、ブラウザ内で処理する。

公開版: https://falls247.github.io/serifu-editor/

## 編集

1. 「フォルダを開く」または「画像を追加」で複数画像を読み込む。画像名の数字順で並ぶ。
2. 各画像の中央で「＋ 男性」「＋ 女性」「✦ 効果音」を追加し、セリフを直接入力。
3. 男性セリフは黒、女性セリフはピンク。吹き出しなし、白い縁取りを必ず付ける。途中でも話者を切替できる。
4. 効果音の漫画エフェクトを選ぶ。「立体」は黒い立体影と傾き、「集中線」は放射線、「スピード」は流線、「震え」は文字ごとの角度・上下変化と震え線。効果音の文字色も変更できる。
5. 右のプレビューで文字をドラッグして移動。選択枠の右下の角でサイズ、上の丸で回転を調整。下の設定では元画像のピクセル単位でX/Y、文字サイズ、回転、配置幅・高さ、白縁の太さ、縦書きを修正できる。
6. 「セリフ交換」は同じ画像内の2レイヤーのテキストだけを交換。男女の色・位置は保持。複製、削除、前後関係、画像別Undo/Redoにも対応。
7. 下へスクロールして次の画像を編集。「編集完了・次へ」は確認済みにして次へ移動。「文字を次の画像へ複製」は画像サイズに合わせて配置を拡縮し、次の画像の既存文字に追加する。
8. 「一括保存」で保存先の親フォルダを選ぶ。その中に日時とランダムID付きの新規フォルダを作り、全画像を元解像度のPNGと再編集用 `serifu-project.json` に保存。選択枠は出力しない。連番で同名の衝突を防ぐ。

## 編集データ・元画像

「編集データを保存」は画像、男女の区分、効果音スタイル、文字と位置を1ファイルに含める。「編集データを読込」で現在の一覧に追加し、再編集できる。旧version 1の吹き出しは、テキストと位置を保って白縁の男性セリフに変換する。旧吹き出しの形状・しっぽは引き継がない。

- 編集は元画像を上書きしない。
- 「一覧から外す」は元ファイルを残す。未保存の当該画像の編集は失われる。
- 「元画像を削除」は、ファイル名を確認後、**実ファイルを完全削除**。ゴミ箱には移動しない。Undoでは復元できない。
- 元画像削除は「フォルダを開く」で直接接続した画像のみ。画像追加、サンプル、編集データからの画像には無効。
- 保存途中の失敗は保存済み枚数と出力フォルダを表示。部分出力は残る。
- ブラウザを閉じる前に一括保存か編集データ保存が必要。自動永続保存なし。

## 起動・公開

Node.js 22以降を用意して実行。アプリ本体に依存パッケージは不要。

```bash
npm start
```

http://localhost:5173 を開く。Windowsから直接起動、またはWSLから起動してWindowsブラウザのlocalhostから利用できる。画像の選択はブラウザ側のファイルシステムで行う。

GitHub Pagesは **Settings → Pages → Source → GitHub Actions** を設定。mainへのpushでチェック・テスト・ビルドを通過した版を自動公開する。Actionsの **Deploy GitHub Pages → Run workflow** からも実行できる。

```bash
npm run build
```

`_site/` へ公開用HTML/CSS/JavaScriptのみ出力する。公開先にNode.jsサーバーは不要。

## 対応・制約

- 新規フォルダへの直接一括保存・元画像削除には File System Access API が必要。PC版Chrome / Edgeと、localhostまたはHTTPSが対象。
- 非対応ブラウザでも複数ファイル・フォルダからの読込、編集、編集データ保存を利用できる。新規フォルダへの直接一括保存・元ファイル削除は無効。
- デスクトップ・iPad横向きでは3列。狭い画面では元画像／セリフ／プレビューを順番に並べる。
- PNG出力。GIFは静止画として扱う。EXIF等のメタデータは引き継がない。書体は端末環境に依存。
- 縦書きは文字単位配置。高度な縦組み約物・ルビには未対応。長文が配置高さを超える場合は文字サイズか配置幅・高さを調整する。
- プレビューは最大1400pxの縮小表示で、出力は元解像度。大量・高解像度画像はメモリ使用量が大きくなるため分割編集を推奨。
- 矢印キー: 1px移動、Shift+矢印: 10px、Ctrl/Cmd+Z: 戻す、Shift追加: やり直す。

## 検証

```bash
npm run check
npm test
npm run build
```

GitHub Actionsでも実行。旧編集データ互換、画像別履歴、セリフ交換、別解像度への複製、回転後のヒット判定とファイル名を検証する。

Pages公開前にはPlaywrightによるブラウザ検証も実行。3列配置、連続編集、黒・ピンク・白縁の描画、ドラッグ、全効果音、編集データ再読込、旧データ変換を確認する。フォルダ保存と元画像削除はテスト用フォルダハンドルで検証し、ユーザーの実ファイルは使わない。ブラウザ検証用の依存はCI内だけに一時導入する。
