# Serifu Editor

複数画像に吹き出し・効果音を配置するローカルWebアプリ。依存パッケージ不要。画像は外部送信せず、ブラウザ内で編集する。

## 起動

Node.js 22以降を用意し、リポジトリ内で実行。

```bash
npm start
```

PC版Chrome / Edgeで http://localhost:5173 を開く。Windowsから直接起動できる。WSLから起動した場合もWindowsブラウザのlocalhostから開き、Windows側のフォルダを選択する。

## 使い方

1. 「フォルダを開く」で画像のあるフォルダへのアクセスを許可。直下のPNG/JPEG/WebP/GIF/AVIFを名前順で読み込む。複数フォルダや「画像を追加」からの追加にも対応。
2. 左の一覧から画像を選び、「＋ 吹き出し」「＋ 効果音」で文字を追加。
3. キャンバス上でドラッグ移動。右側でテキスト、座標、幅・高さ、文字サイズ、回転、色、縦書き、吹き出し形状としっぽ位置を変更。プレビューへ即時反映。
4. 「セリフを入れ替え」で同じ画像内の2レイヤーのテキストだけを交換。複製、前後関係変更、削除、画像単位のUndo/Redoにも対応。
5. 「一括保存」で保存先の親フォルダを選ぶ。その中に日時とランダムID付きの新規フォルダを作り、全画像を元の解像度のPNGと再編集用の `serifu-project.json` に保存。選択枠は出力されない。連番で同名画像の衝突を防止。
6. 「編集データを読込」で画像と編集可能な文字レイヤーを追加して再編集。画像を含むので元画像の移動後も再開可能。

## 削除と保存に関する注意

- 「一覧から外す」は元ファイルを残す。未保存の当該画像の編集は失われる。
- 「元画像を削除」は**選択した実ファイルを完全削除**。ファイル名を確認するダイアログを表示。ゴミ箱には移動しない。アプリのUndoでは復元できない。
- 元画像削除は「フォルダを開く」で直接読み込んだ画像のみ有効。画像追加、サンプル、編集データ読込からの画像には無効。
- 編集で元画像を上書きしない。保存途中に失敗した場合、保存済み枚数と出力フォルダを表示。部分出力は残る。
- ブラウザを閉じる前に一括保存または編集データ保存が必要。自動永続保存なし。

## 対応・制約

- フォルダ読込・元ファイル削除・新規フォルダへの一括保存には File System Access API と安全なコンテキスト（localhostまたはHTTPS）が必要。PC版Chrome / Edgeを対象とする。
- iPad/Safariなど非対応ブラウザでは複数ファイル追加、編集、編集データのダウンロードが利用できる。フォルダ直接保存と元ファイル削除は利用不可。
- PNG出力。GIFは静止画として扱う。EXIF等のメタデータは引き継がない。フォントは端末環境に依存。
- 縦書きは文字単位配置。高度な縦組み約物・ルビには未対応。長文は幅で折り返すが、高さを超える場合は文字サイズか枠を調整する。
- 全画像をメモリに保持するため、大量・高解像度画像は分割して編集する。
- 矢印キー: 1px移動、Shift+矢印: 10px、Ctrl/Cmd+Z: 戻す、Shift追加: やり直す。

## 検証

```bash
npm run check
npm test
```

GitHub Actionsでも構文チェック・回転後のヒット判定・保存ファイル名・初期レイヤー設定を検証する。
