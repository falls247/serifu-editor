# 効果音の文字配置・ブラシ輪郭の実装報告

作業日: 2026-10-10。ブランチ: `feat/dialogue-balloon-controls`。開始時の作業ツリーはクリーン。ユーザーの指定により同じブランチで作業し、コミット・pushは行っていない。

## 原因と変更

文字のサイズ変化・回転・歪みを確定する前に、フォントサイズと一定のadvanceから位置を決めていた。そのため字形の黒画素領域と文字送りが一致せず、細い記号や文字間の余白、サイズばらつき後の間隔が大きくなっていた。作業前の「ドカーン！」は幅520pxで末尾が折り返されることを再現した。

吹き出しの現行ブラシは3回strokeではなく、すでに7本の繊維パッチ方式だった。ただし筆圧と濃淡が独立せず、キャプションへ共通利用できなかった。今回、Geometry・字形配置・筆圧／質感・最終描画を分離した。

## 採用したアルゴリズム

文字はGrapheme分割 → 先細り／サイズ変化 → 記号回転／個別回転 → 縦横倍率／傾き／歪み → 実インクの変形領域 → 輪郭間送り → 相関Jitter → 間隔補正／折返し → 全体BBox／収まり補正 → 既存の掠れ／縁／残像描画の順で処理する。

初期評価に `actualBoundingBox*` を使い、強度35%以上の必要な隣接ペアだけ局所アルファマスクを解析する。マスクは最大128pxで、行／列のインク突出量と実インクBBoxを保存する。配置の乱れは3文字周期の滑らかな変動80%と局所変動20%。輪郭の入れ子と実重なりを制限し、句読点の右上補正、長音・括弧の回転、改行、先細りを保持する。

ブラシは基準輪郭を弧長でサンプリングし、尖り・テール・矩形角を必ず含める。周期的な連続関数で疑似筆圧と線幅を決め、可変幅ポリゴンを私有Canvasへ描く。そのマスクへ、進行方向に沿う繊維の欠け、濃淡、微小な輪郭の揺れ、弱い毛羽立ちを適用する。塗り・本文クリップ・影は元のGeometryを使い、背景や本文を消去しない。

`perfect-freehand`、筆先スタンピング、`opentype.js` を評価し、閉曲線と鋭角の保持、Canvasのフォールバック字形との一致を優先して独自処理を採用した。新しいランタイム依存はない。判断の根拠と参考資料は [ADR-0014](adr/0014-optical-lettering-and-brush-strokes.md) に記録した。

## 追加パラメータと推奨値

| パラメータ | 範囲・単位 | 互換既定／意味 |
|---|---|---|
| `kerningMode` | `standard` / `optical` | `standard`。従来配置を保持 |
| `kerningStrength` | 0〜100% | 0。0では追加の詰めなし |
| `minimumGlyphGap` | 0〜100px | 2。白縁は追加して評価 |
| `overlapAllowance` | 0〜30% | 0。重なり量の上限 |
| `rotationJitter` | 0〜45° | 0。文字単位の角度変化 |
| `verticalJitter` | 0〜30% | 0。字形サイズに対する上下変化 |
| `spacingJitter` | 0〜30% | 0。文字送りの変化 |
| `glyphOverlap` | 0〜30% | 0。上限との小さい方を使用 |
| `borderStyle` | `solid` / `brush` / `dry-brush` | `solid`。通常線は既存stroke |
| `brushRoughness` | 0〜100% | 既存項目。輪郭と弱い毛羽立ち |
| `brushPressureVariation` | 0〜100% | 新規35。連続する線幅変化 |
| `brushTexture` | 0〜100% | 新規20。方向に沿う欠け |
| `brushOpacityVariation` | 0〜100% | 新規15。インクの濃淡 |
| `brushSeed` | 0〜4294967295の整数 | レイヤーから生成し保存 |

既存の `sizeVariation`、`horizontalJitter`、`glyphSeed` は継続利用。新配置ではサイズ変化後の寸法を測り、左右ずれにも相関変動を使う。重なり量は占有長の最大10.5%に制限する。非常に狭いボックスでは全体を縮小するため、最小間隔と文字サイズも描画時に同じ倍率で縮む。

| 推奨プリセット | 主な設定 |
|---|---|
| 効果音・密集レタリング | 詰め85%、間隔2px、回転4°、サイズ5%、左右2%、上下2%、字間3% |
| 効果音・荒々しい手描き配置 | 詰め90%、間隔1px、回転18°、サイズ18%、左右12%、上下8%、字間15%、重なり上限18%／指定15% |
| 吹き出し・手描きペン | 揺れ25%、筆圧40%、掠れ15%、濃淡10% |
| 吹き出し・掠れ筆 | 基本幅7px、揺れ55%、筆圧65%、掠れ75%、濃淡35% |
| キャプション・手描き枠線 | 基本幅4px、揺れ30%、筆圧45%、掠れ25%、濃淡15% |

既存プリセットと既定IDは維持する。文字配置／ブラシの詳細欄から数値とseedを編集でき、再生成をUndo/Redoできる。

## 互換性と保存

JSONは版1〜9、高速 `.serifu` は内部プロジェクト版6〜9を読み、保存は版9。コンテナ版1とIndexedDBスキーマは変更しない。新設定を旧アプリが黙って捨てないようモデル版を上げた。v9の編集データは新しいアプリで開く必要がある。

旧データで新設定が欠けている場合、文字配置は `standard`、追加Jitterと重なりは0、キャプションは通常線を補う。旧吹き出しのブラシは互換エンジンで描画し、ブラシ設定の編集時に新方式へ移行する。旧ブラシの欠損roughnessは従来の50%を補う。

単体コピー、複製、一括コピー、Undo/Redo、JSON、高速形式、一時保存で全設定とseedを保持する。異なる画像サイズへのコピーでは最小間隔も文字サイズと同じ小さい方の倍率で拡縮し、割合とseedは保持する。ユーザープリセットには配置seed／ブラシseedも保存する。組み込みプリセットと旧プリセットの未指定seedは適用先を保持する。

## 残存する制約

- 輪郭解析は最大128pxの局所マスクによる近似。精密なベクトル字形解析やOpenType縦組み・JIS禁則の全面実装ではない。
- 疑似筆圧であり、実ペン入力や任意の画像筆先を読み込む機能はない。
- 極端な歪み、狭いボックス、長文は全体縮小で収まりを補正する。必要ならボックスを広げる。
- 字形サーフェスとブラシサーフェスはそれぞれ200万画素上限で品質を制限する。大きい図形では微細な掠れが弱くなる場合がある。
- キャッシュは有限。多数の異なる文字・サイズ・seedを続けて編集すると古い解析と画像を再生成する。初回描画にはCPU負荷がある。
- ブラウザ、端末書体、フォント読込条件が異なる環境間の画素一致は保証しない。
