## 実装済みの修正

- ライブプレビューにフォーカスがあり、文字オブジェクトを選択中にEnterを押すと、選択対象の本文欄へ移り、末尾から入力できる。セリフ・吹き出し・キャプション・効果音に対応する。既存の本文は保持し、入力モードへの移行だけではUndo履歴を追加しない。
- 複数選択時は最後に選択した対象を入力先にし、複数選択を維持する。ライブプレビューFOCUSでも利用できる。IME変換中・修飾キー付き・初回イベントがキーリピート・ドラッグ中・クロップ中・原寸プレビュー表示中・閲覧専用・未選択・マスク加工では本文入力への切替を行わない。本文欄のEnterは通常の改行として扱う。
- 操作説明書の「画面の見方」「ショートカット」にEnterの手順を追加した。
- 「画像加工・SAM3」に、元画像のポイント指定用FOCUSの初期状態、カーソル基準の100%表示と追従、ポイント追加、枠外への移動による解除、オフ操作、候補選択・タッチでの対象外条件、ライブプレビューFOCUSとの違いを追加した。
- 同節の確定ボタン名も実装と照合し、誤っていた「OK」を実際の表示「選択候補を加工に追加」に修正した。
- ルートに `AGENTS.md` を追加し、作業前の更新ルール参照、同じ差分での説明書更新、完了報告の記載事項を必須化した。
- `npm run check` に説明書更新漏れチェックを組み込んだ。説明書を更新しない内部変更には、`dev/docs/documentation-impact.md` への新しい判断理由を求める。ステージ済み・未ステージ・未追跡・コミット済みの差分に対応し、以前の判断理由の使い回しや説明書の削除では通過しない。
- CIと公開ワークフローにも比較元を指定した。ローカル作業中だけでなく、PR・pushのコミット済み差分も確認する。
