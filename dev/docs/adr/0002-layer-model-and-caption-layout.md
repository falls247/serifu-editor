# ADR-0002: 独立レイヤーと制約付き描画順を採用する

- 状態：採用済み（既存実装の事後記録）
- 記録日：2026-10-10（日本時間）
- コード基準：`b721ad78a7c658f23b83a0da1f6ed13c950c9696`

## 背景

台詞の文字は男性が黒、女性がピンクで白縁を付ける。吹き出しは必要な場合だけ追加し、端からはみ出す楕円として調整する。モノローグ用キャプションは本文と矩形を一緒に編集し、中央揃えや自動文字サイズに対応する。この3用途を同じ文字ボックスで扱うと、設定と重なり順が曖昧になる。

## 決定

`kind` で4種類を区別し、`x`／`y`／`w`／`h`／`rotation` を共通の位置情報にする。移動・選択・回転は共通経路を使い、種類ごとの形状・文字配置は専用モジュールに分ける。

| kind | 内容と既定 |
|---|---|
| `dialogue` | 台詞本文。男性 `#111111`、女性 `#ef4b91`、白縁、縦書き |
| `sfx` | 効果音本文と書体・漫画エフェクト。縦書き |
| `balloon` | 本文を持たない楕円。白、25%透過、テールなし。手動追加 |
| `caption` | 本文を持つ矩形。白背景25%透過、黒枠、縦書き、上下左右中央、自動追従OFF。手動追加 |

吹き出しは台詞・キャプションから独立し、文字より必ず下に描く。効果音との上下は `sfxOrder` で指定し、`paintOrder` が次の順序を組み立てる。

- 前面吹き出しがない場合：背面吹き出し → その他のレイヤーを元の相対順で描画。
- 前面吹き出しがある場合：背面吹き出し → 全効果音 → 前面吹き出し → 台詞・キャプションを元の相対順で描画。

これは任意のZ値や特定の効果音だけとの関係ではない。選択判定も `paintOrder` の逆順を使い、見えている前面のレイヤーを優先する。

楕円とテールを一つのパスで塗り、半透明の接続部が二重に濃くならないようにする。テールの先端が楕円内にあるときはテールを描かない。ヒット判定は回転を戻したローカル座標で楕円とテールの実形状を調べる。

## キャプションの配置

本文は枠線の半幅と余白を差し引いた内部領域に置き、はみ出す部分をクリップする。透過率は背景の塗りにだけ適用し、枠線と本文には適用しない。

`alignX` は左／中央／右、`alignY` は上／中央／下。方向は回転前のボックスのローカル軸を基準とする。横書きは各行を左右へ、縦書きは各列を上下へ揃える。明示改行と空行を保持し、縦書きの列は右から左へ進む。

`autoFit` は実際のフォントメトリクスで収まる最大サイズを1〜500pxの0.5px刻みで探索する。保存された手動 `size`（8〜500px）は変更しない。OFFに戻すとそのサイズを使う。リサイズはボックスだけを変え、ONなら再計算、OFFなら手動サイズのままクリップする。最小サイズでも収まらない場合はUIに状態を表示する。

## 代替案と比較

- 台詞に吹き出しを内包すると、複数の文字で共有する楕円や文字と独立した位置調整が難しい。独立レイヤーにする。
- 単純な配列順だけで描画すると、吹き出しを後から追加した際に台詞を隠す。用途に必要な順序制約を優先する。
- 自動追従で手動サイズを書き換えると、OFFへ戻しても元の指定が失われる。描画時に算出する。

## 結果と制約

新しいレイヤーを追加するときは、描画だけでなく正規化、入力UI、選択、コピー、履歴、保存形式を揃える。吹き出し・キャプションは台詞／効果音プリセットと本文入れ替えの対象にしない。

キャプションは矩形内部の配置であり、台詞や任意の吹き出しへの自動組版は行わない。描画順を自由なZ値へ拡張する場合は、文字が吹き出しより下にならない条件を別途設計する。
