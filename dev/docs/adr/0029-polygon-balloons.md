# ADR-0029: 多角形の吹き出しと頂点数のランダム生成

- 日付: 2026-10-16
- 状態: 採用
- 関連: [ADR-0013](0013-speech-colors-and-balloon-parameters.md)、[ADR-0016](0016-text-position-and-balloon-content.md)

## 背景

楕円・歪み長方形・尖り形に加え、直線の辺を持つ多角形の吹き出しと、頂点数をランダムに決める操作が必要になった。

## 決定

1. `balloon.shape='polygon'` と整数の `polygonCount` を追加する。頂点数は3〜60、初期値は6。尖り形の `spikeCount` は独立した値として保持し、形状を切り替えても各頂点数を保持する。
2. 多角形の頂点を直線で接続する。`distortion=0` では正多角形を幅・高さに合わせて拡縮し、歪み度を上げると頂点の角度と半径を変える。形状は既存の `shapeSeed`・頂点数・歪み度から再現する。角度のばらつきを制限し、3頂点でも中心が形状内に残るようにする。
3. 描画・クリッピング・当たり判定・テールの付根に同じ直線辺を使用する。ブラシ枠線にも同じ輪郭を渡し、頂点を曲線のサンプリングで丸めない。
4. カードとプレビュー横の設定欄に「多角形の頂点数」と「頂点数をランダム生成」を表示する。入力とスライダーは整数として同期する。ランダム生成は3〜60のうち現在値以外から均等に選び、変更1回をUndoの単位とする。seedは保持する。「形状を再生成」は頂点数を保持してseedを変更する。
5. コピー・プリセット・JSON・高速形式・一時保存に頂点数を保持する。旧吹き出しに `polygonCount` がない場合は6を補完する。旧プリセットでは適用先の頂点数を維持する。
6. `PROJECT_VERSION=15`、`RENDER_VERSION=12`。JSONは1〜15、高速形式の内部プロジェクト版は6〜15、一時保存は3〜15を受け付ける。コンテナ版2は維持する。

## 代替案

- 尖り形と同じ頂点数を使用する: 尖り形の下限6と多角形の下限3が異なり、切り替えで設定が失われるため、別フィールドにする。
- 描画時に頂点数を抽選する: 再描画・PNG・復元の形状が揺らぐため、ボタン操作時に値を確定して保存する。
- 多角形を細かい曲線サンプルで描画する: 頂点が欠ける可能性があるため、正確な頂点を接続する。

## 結果と制約

- 保存版15は旧アプリの読込対象外。旧編集データは引き続き読める。
- 頂点数が少ない多角形では文字の描画領域が狭くなる。文字が輪郭で切れる場合は文字位置・サイズ・吹き出しの大きさを調整する。
- 頂点数が多く歪みが小さい場合は楕円に近い見た目になる。
- 輪郭で切れる文字にはCanvas実装間のアンチエイリアス差があるため、CanvasとOffscreenCanvasの画素比較用文字は三角形でも内側に収まるように配置する。

## 関連コードと検証

- `src/balloons.js`: 固定seedの頂点生成、直線辺と放射方向の交点、正確な輪郭、ランダム頂点数。
- `src/model.js`・`src/presets.js`: 入力検証、旧データ補完、保存とプリセットの保持。
- `src/app.js`・`index.html`・`style.css`: 多角形専用の設定表示、同期、ランダム生成とUndo。
- `test/polygon-balloons.test.mjs`: 全3〜60頂点、seedと歪み度の組み合わせ、辺・当たり判定・テール、入力検証、プリセット、コピー、JSONと高速形式。
- `npm run test:polygon-browser`: UI・スライダー・ランダム生成・Undo/Redo・形状切替・seed・プリセット・コピー・テール・Canvas・PNG・JSON・高速形式・一時保存・モバイル幅。
- 保存版更新に伴い、マスクがマニフェストへ混入しない検証を文字列検索から `data` プロパティの不在検証へ変更した。短い圧縮値 `15` がプロジェクト版15と一致して誤判定するのを防ぐ。
