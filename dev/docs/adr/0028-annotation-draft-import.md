# ADR-0028: 画像別JSON下書きの取り込みと自動配置

- 日付: 2026-10-16
- 状態: 採用

## 背景

別アプリが画像のコピーと一緒に保存したセリフ・吹き出しの下書きを、フォルダを開くだけで編集可能なオブジェクトへ変換する。外部形式には座標や書式がないため、現在の既定プリセットと独立した配置処理を使用する。

## 決定

- `img001.jpg` に対し、同じディレクトリの `img001.jpg.json` を取り込む。拡張子を置き換えた `img001.json` は対象外。フォルダ選択APIと代替のフォルダ入力に対応し、代替入力は相対パスで対応付ける。通常の画像追加・ドラッグ追加では取り込まない。
- 外部JSONは `schemaVersion: 1`、画像の実ファイル名と一致する `imageFile`、`annotations` 配列を持つ。`savedAt` は配置に使用しない。既存の編集データ形式とは別の入力形式とし、編集データ版14は維持する。
- `dialogue` を男性／女性セリフ、`caption` をキャプション、`sound_effect` を効果音、`speech_bubble` を本文付き吹き出しへ変換する。1注釈につき1オブジェクトとし、本文・改行・空文字と配列順を保持する。セリフの話者はJSONを優先し、吹き出しの話者は現在の既定プリセットを使用する。
- JSON全体の解析・版・画像名・配列の検証に失敗した場合は下書き全体を見送り、画像は開く。不正な個別注釈はその項目だけを見送る。書体の読み込みや配置処理の失敗も画像の追加を妨げない。警告には対象ファイル名と理由を含める。
- 必要な書体を読み込んでから占有範囲を計測し、右上から左へ、横幅を超えたら下段へ配置する。段の上端を揃え、高さは段内の最大占有高さとする。余白と間隔は画像短辺の2%（四捨五入、最低2px）。回転、文字のはみ出し、輪郭、装飾、しっぽ、影を含めて非重複を判定する。
- 初期サイズで収まらなければ、枠・文字・装飾の寸法を共通倍率で縮小する。モデルの既存下限（枠30px、文字8pxなど）を維持し、最小状態でも収まらないときは全件を残したまま下段へ続ける。単体で幅を超えたオブジェクトは右端を基準に左へはみ出す。画像外配置は警告する。
- 生成後は編集済み・未確認とし、初期読み込み自体にはUndo履歴を作らない。その後の編集、JSON／高速形式、一時保存は既存機能を使う。元画像・下書きJSONは変更せず、読み込み時に専用の追跡メタデータを追加しない。

## 結果と制約

構図や人物の位置は認識せず、読み順を保つ下書き配置を行う。必要に応じてプレビューから位置や書式を調整する。件数が多い場合は文字が小さくなる。

縮小限界で画像外に置いた部分は、プレビューの画像領域やPNG出力には含まれない。オブジェクト一覧と位置設定から手動で調整する。フォルダを繰り返し開く場合は従来どおり新しい画像ページとして追加する。保存済みプロジェクトの復元では元の下書きを再取り込みしない。

## 検証

単体テストで形式の検証、変換、配列順、非破壊の縮小と配置を確認する。`npm run test:annotation-drafts` はテスト用フォルダと模擬フォルダハンドルを使用し、両方のフォルダ入力、描画範囲、既定書式、異常入力、縮小限界、編集・保存・再読込・一時保存を検証する。

2026-10-16実行結果：`npm test` は224件すべて成功。`npm run check`（110ファイル）、`npm run build`、`npm run test:annotation-drafts`、既存の `node scripts/editor-regression-smoke.mjs`、`git diff --check` も成功した。新規ブラウザ検証では同梱書体の読み込み成功／失敗、尖ったキャプションと句読点の実描画が計測範囲内に収まることも確認した。OSのフォルダ選択ダイアログ自体の操作は自動検証対象外。
