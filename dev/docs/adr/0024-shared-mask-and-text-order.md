# ADR-0024: マスク加工と文字の重なり順を共通化する

- 状態：採用
- 記録日：2026-10-11
- 置換する判断：[ADR-0023](0023-sam3-mask-effects-and-storage.md)の文字を常にマスクより前面へ描く規則、編集データ版12での出力

## 背景

ユーザーから、マスクカードをセリフと同じ選択時展開・非選択時短縮表示にし、マスクと文字を混在させて前面・背面へ移動する指示を受けた。版12はマスクの追加順で画像加工を済ませた後に文字を描くため、共通の重なり順を保存できない。

## 決定

- 文字と加工は`layers`と`maskEffects`へ分けたまま保持し、各オブジェクトの`layoutOrder`で共通の描画順を表す。文字専用コピー・プリセットへマスクを混在させない。
- 共通の`paintOrder`をカード一覧、描画、前面・背面操作、Canvas上の選択で使う。一覧は背面から前面の順。4操作とUndo/Redoをマスクにも適用する。
- 明示的な順序がない旧データは、マスクの`createdOrder`順→既存の文字配列順で表示する。最初の順序変更で全オブジェクトに連番を付ける。文字の複製・貼付けではコピー元の順位を持ち込まず、前面へ追加する。
- 非選択のマスクカードは名前・方式・非表示状態だけを2行以内で表示する。選択すると加工・座標・表示・削除・順序操作を展開する。
- 前面のマスクは範囲内の文字も覆う。各加工は元画像の画素から生成し、マスクの穴では下位の描画を保持する。ぼかし0pxは対象内を元画素へ戻し、透明画素も復元する。文字を含む合成画像へ再びぼかしを適用しない。
- 文字より背面の連続マスクは従来の画像合成経路を使う。文字より前面のマスクはbboxサイズのRGBAと二値coverageを生成し、対象画素を消去してから元画像由来の加工を合成する。文字の間にマスクを置いても、マスク外の画素と下位オブジェクトを保持する。
- 編集データとJSONは版13、コンテナは版2を維持する。旧JSON版1〜12とコンテナ版1／2を読み込む。旧版への`layoutOrder`混入は拒否し、旧アプリでの無言の順序欠落を防ぐ。旧文字順の移行条件は版11未満のまま維持する。
- 順序はオブジェクトの設定として履歴・JSON・コンテナ・一時保存へ保存し、PNGキャッシュとサムネイルの変更検知にも含める。画面、Worker、原寸表示、PNGで同じrendererを使う。

## 代替案と結果

マスク同士だけを並べ替える案は、文字との共通順序というユーザー指定を満たさない。マスクを`layers`へ直接入れる案は文字専用機能への影響が大きいため採用しない。

版13の保存結果は旧アプリでは開けない。前面へ置いたマスクが文字を覆う動作は意図した仕様。原画像の画素とcoverageを使うため、透明PNGでも範囲外を消去しない。
