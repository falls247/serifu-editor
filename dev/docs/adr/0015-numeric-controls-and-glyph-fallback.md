# ADR-0015: 数値調整UIの連動と空字形のフォールバック

- 日付: 2026-10-10
- 状態: 採用
- 関連: [ADR-0005](0005-fonts-and-manga-typography.md)、[ADR-0014](0014-optical-lettering-and-brush-strokes.md)

## 背景

配置seedの再生成やUndoでカードDOMを再構築すると、効果音の詳細設定が閉じた。詳細の数値は直接入力だけで、描画を見ながら連続調整できなかった。効果音の輪郭色は描画側に対応がある一方、カード・モデルの正規化・プリセットでは扱っていなかった。

851チカラヨワクの `♥` と `♡` はcmapに登録されているが、glyfの字形データ長が0。CSSのフォント候補に別書体を追加するだけでは、登録済みの空字形から切り替わらない。

## 決定

1. 詳細の開閉状態はページ内のレイヤーIDと設定群名で保持する。カード再構築・Undo・プリセット適用・ページのアンマウント前に記録し、再表示時に復元する。描画・保存データには含めない。
2. レイヤーカードと位置調整の各数値を、numberとrangeの組にする。既存の `data-field` はそのまま残し、追加側は `data-numeric-field` を使う。同じ正規化・Undo・描画更新を通し、直接入力、増減、ポインタでの連続調整、キーボード操作を連動させる。
3. 数値入力の既存の上限・下限・刻みを維持する。位置のスライダーは画像寸法を基準にし、配置幅・高さは通常の調整範囲を画像寸法の2倍までにする。直接入力した値が範囲を超えたらスライダー範囲も広げる。コピー等で刻みに合わない端数が生じた場合は、スライダーを連続値にして同じ値を表示する。モデルの座標・寸法は丸めず、UI表示だけ15桁の有効数字で小数誤差を整える。
4. 同梱フォントの候補順は、選択した書体、GEKIFUDE SFX、従来の端末書体とする。存在しない文字はCanvasの通常の文字単位フォールバックに任せる。
5. 登録済みの空字形には `glyphFontDescription()` を使う。64pxで実インクのBounding Boxを測り、可視文字の4つの境界値がすべて0なら、その書記素だけGEKIFUDE SFXへ切り替える。空白や不可視の制御文字は置換しない。最大2,048件をキャッシュし、フォント読込時に既存の描画キャッシュと共に破棄する。
6. 標準配置、輪郭詰め、字形マスク、セリフ、吹き出し本文、キャプションの計測・描画で同じ選択処理を使う。プレビュー・PNG準備・画像Workerは、選択した書体に加えGEKIFUDE SFXの読込を待つ。
7. 効果音でも既存の `textOutlineColor` と `outline` を使う。輪郭色の欠損値は従来と同じ白、太さは0〜80px、0.5px刻み。コピー・プロジェクト・一時保存・Undo・ユーザープリセットへ反映する。旧プリセットに輪郭色がなければ対象レイヤーの色を維持する。
8. 保存形式の構造は変更せず、プロジェクト版9を維持する。描画結果が変わるため、PNGキャッシュの描画版は6へ更新する。ライブラリ・フォントファイル・配布条件は追加しない。

## 代替案と結果

- CSSの候補追加だけでは、登録済みの空字形を救済できない。
- ハート2文字を固定で置換すると、他の書体にある正しいハートまで置換し、別の空字形も漏れる。実インクの有無で判断する。
- TTFの書き換えは原本保持・配布条件・ハッシュ検証に影響する。Canvas側で判定する。
- フォント全体の差し替えは選択した書体を失う。対象書記素だけを切り替える。

GEKIFUDEにもない文字は従来の端末書体へ進む。端末書体やフォント未読込時の一時表示まで、環境間の画素一致を保証するものではない。追加読込は既存のGEKIFUDE TTF約208KiBで、一度読み込むと再利用する。uint32のseedなど広い範囲はスライダーのポインタだけでは細かく指定しにくく、直接入力・増減を併用する。

## 追加修正: 吹き出し・キャプションのカード

吹き出しとキャプションは、専用カードを追加した直後の早期終了により、共通の数値UI追加と詳細開閉状態の復元を通っていなかった。`renderCards()` のカード追加処理を共通化し、全種類でスライダー生成と開閉状態の復元を実行する。数値範囲・刻み・モデル・保存版は変更しない。

`data-action` ボタンへのフォーカスではページ選択を変更せず、既存のクリック処理で選択して操作する。別ページへフォーカスした瞬間のカードの折り畳み・展開により、pointerdownとpointerupの間でボタン位置が変わり、初回クリックが失われるため。入力欄とカードの選択見出しは従来どおりフォーカスで選択する。

[speech-style-smoke.mjs](../../../scripts/speech-style-smoke.mjs) で吹き出し14組・キャプション9組の数値UI、端数と負の値、キーボードとポインタ操作、右側設定欄との同期、操作単位のUndo/Redo、筆跡再生成後の詳細保持、保存・再読み込み、モバイルの収まりを検証する。
