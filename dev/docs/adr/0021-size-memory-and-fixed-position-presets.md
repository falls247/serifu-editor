# ADR-0021: 文字サイズの記憶と位置を保持するプリセット

- 日付: 2026-10-11
- 状態: 採用
- 関連: [ADR-0009](0009-named-layer-presets.md)、[ADR-0020](0020-full-size-preview-and-numeric-ui.md)

## 背景

文字サイズ70pxを繰り返し入力していた。サイズだけを記憶して反映する操作が必要になった。また、書式や効果を変える目的でオブジェクトのプリセットを適用すると、保存済みのXY座標まで反映されて現在位置が変わっていた。

## 決定

1. 文字サイズの数値欄を最大60px幅にし、右に「設定」「反映」を並べる。操作群は位置調整グリッドの2列を使い、下のサイズスライダーを維持する。狭い画面でも数値とボタンが収まる幅を確保する。
2. 「設定」は現在選択中の1件のサイズを記憶する。「反映」は記憶した整数のピクセル値を選択中の1件へ適用する。画像サイズによる拡縮や、他の書式・座標の変更は行わない。適用はUndoで戻せる。同じ値の再適用や記憶だけの操作はオブジェクトの履歴を増やさない。
3. 記憶するサイズは全画像・全オブジェクト種類で共通の1件とし、初期値70px、範囲8〜500pxとする。キャプションの自動サイズ調整がONの間は、サイズ欄と同様に両ボタンを無効にする。
4. `preferences.fontSizePreset`を既存のlocalStorageへ保存し、JSON・高速形式の編集データと一時保存にも同梱する。旧設定で欠損していれば70pxを補完する。欠損した旧プロジェクトを取り込む際は現在記憶している値を維持し、値を持つプロジェクト・一時保存は保存されたサイズを復元する。編集データ版10と設定版1は維持する。
5. セリフ・効果音・吹き出し・キャプションのプリセットから、`xRatio`と`yRatio`を除く。新規保存と標準プリセットには位置を含めず、旧プリセットのXY指定も適用時に使わない。設定の正規化では旧XYフィールドを取り除いて再保存する。オブジェクト本体のXY座標は保存・コピー・復元に必要なので維持する。
6. 幅・高さ、書式、話者、効果、本文の内部オフセットなど、XY以外のプリセット項目は従来の適用を維持する。新規オブジェクトへ既定プリセットを使う場合も、新規作成時の初期XY位置を保持する。

## 代替案と結果

- オブジェクトの全設定を保存するプリセットとは用途が違うため、文字サイズの記憶は独立した数値にした。種類や画像ごとに複数値を持つ方式は採用しない。
- 旧プリセットの座標だけを削除しても、直接適用された旧データで位置が変わる。保存対象と適用対象の両方からXYを外す。
- 数値欄を縮めるだけでは4列の狭い設定欄で数字が読めなくなる。操作群の領域を2列分にして、数値欄自体は短く保つ。

同じ位置で書式・効果を切り替えられる。旧アプリではXYのない新しいプリセットを利用できない場合があるため、更新後のアプリを使う。ブラウザへの記憶に失敗した場合は既存のエラー表示を使い、このタブでの値を保持する。

## 検証

- `test/presets.test.mjs`: 初期サイズ、範囲と不正値、旧設定の補完、全4種類のXY除外、旧データと標準プリセット適用時の位置保持、入力データを変更しない正規化。
- `scripts/font-size-preset-smoke.mjs`: 記憶・反映、画像サイズが違う全4種類への固定ピクセル反映、Undo/Redo、自動サイズ調整、再読込・JSON・高速形式・一時保存の復元、旧プロジェクトでのサイズ維持、旧プリセット・標準プリセットのXY保持、新規プリセット保存、9種類の画面幅での配置。
- 吹き出し・キャプション・効果音の既存ブラウザテストで、数値スライダー、書式変更、プリセット、画像と編集データの保存を確認する。

実行結果: 単体テスト18ファイル、ブラウザテスト3本（文字サイズの記憶・吹き出し／キャプション設定・効果音設定）、構文チェック、静的ビルド、`git diff --check`が成功。文字サイズの操作群は9種類の画面幅で数字と両ボタンが画像行に隠れないことを確認した。
