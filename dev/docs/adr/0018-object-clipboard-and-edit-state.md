# ADR-0018: 画像間のオブジェクトコピー、現在の編集情報による状態判定、話者付きプリセット

- 日付: 2026-10-11
- 状態: 採用
- 関連: [ADR-0003](0003-copy-and-history.md)、[ADR-0009](0009-named-layer-presets.md)

複数選択、クロップ・回転を含む編集済み判定、編集データ版10は[ADR-0019](0019-multi-selection-and-image-edits.md)で拡張。

## 背景

選択オブジェクトのコピーはプレビューにフォーカスがある場合に限られており、サムネイルで画像を切り替えた直後は貼り付けが動かなかった。全オブジェクトを削除・カットしても編集済みフラグが残り、編集済み画像だけを保存する操作にも含まれていた。吹き出しプリセットでは話者を保存せず、女性用として保存した設定から男性の吹き出しが作られていた。

## 決定

1. Ctrl／⌘+C/Vを現在の画像の選択オブジェクトへ適用する。サムネイルやカードの見出しにフォーカスがあっても動作し、画像ジャンプの選択後は対象プレビューへフォーカスを移す。入力欄・編集可能要素・IME変換中では従来どおり通常の文字操作を維持する。
2. セリフ・効果音・吹き出し・キャプションの全種類で、コピー時のスナップショットと画像寸法を保持する。別の表示範囲へ移動して元ページがアンマウントされてもクリップボードを維持する。拡縮・20pxずつの貼り付け位置調整・画像別の履歴は従来方式を使う。
3. 編集済みは現在の `layers.length > 0` から決める。全削除・カット・Undo／Redo・JSON／高速形式／一時保存の読込で同じ基準を使い、過去に保存された不整合な `edited` フラグを補正する。確認済みの `done` は別に保持する。
4. 全削除もプロジェクト全体の変更として扱い、一時保存や編集データの保存で削除を記録できるようにする。Undo履歴が残っていても、現在のオブジェクトが0件なら未編集とする。
5. ユーザーのセリフ・吹き出しプリセットに `speaker` を保存し、適用時は本文を保持して男性／女性設定を復元する。話者を手動変更した場合は `presetId` を外す。「男性／女性セリフを追加」はボタンで指定した話者を優先し、既定プリセットの話者と異なる場合はカスタム扱いにする。話者指定のない「吹き出しを追加」はプリセットの話者を使う。
6. 組込みプリセットと話者が未保存の旧プリセットは適用先の話者を維持する。組込みの標準プリセットが「女性セリフを追加」を男性へ戻さないようにする。旧プリセットの話者は名前から推測せず、正しい話者を指定して再保存する。
7. 任意フィールドの追加として、プリセット版1・編集データ版9を維持する。

## 代替案

- 画像切替時に必ずプレビューへフォーカスする方式だけでは、カードの見出しや確認ボタンからの操作が制限される。文字入力のガードを維持した共通ショートカットにする。
- 編集した履歴から編集済みを決めると、元画像に戻っても保存対象に残る。現在のオブジェクトの有無を採用する。
- 旧プリセット名から話者を推測すると、任意の名前で誤判定する。未保存フィールドは補完せず再保存に委ねる。

## 結果と制約

画像を選び直した直後にオブジェクトを貼り付けられ、全削除した画像は「編集済みだけ保存」から外れる。全削除後の状態を保管する際は、編集データまたは一時保存を使う。既存の女性プリセットに話者情報がない場合、修正後に再保存が必要。クリップボードはタブ内のメモリにあり、ページ再読込では失われる。

## 検証

- `test/presets.test.mjs`: 男性／女性と自動文字色の保存・復元、旧／組込みプリセットの互換性、不正な話者の拒否。
- `test/renderer.test.mjs`、`test/balloons.test.mjs`: カット・Undo／Redoでの編集済み判定、不整合な履歴フラグの補正。
- `scripts/clipboard-state-smoke.mjs`: 全4種類の表示範囲を跨ぐコピー、元オブジェクト編集後のスナップショット保持、繰り返し貼り付け、ネイティブ文字コピペ、全削除・カット・保存復元、女性プリセットの新規追加・Undo／Redo・再読込。
- `scripts/balloon-smoke.mjs`: カット後の一時保存を未編集として扱うよう、従来の期待値を更新。

実行結果: 関連単体テスト、構文チェック、追加したブラウザテストと既存5本（通常操作・吹き出し・セリフ設定・500件一覧・保存復元）、静的ビルドが成功。
