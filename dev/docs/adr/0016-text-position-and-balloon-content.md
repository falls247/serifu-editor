# ADR-0016: 吹き出し・キャプションの文字位置と改行領域

- 日付: 2026-10-10
- 状態: 採用
- 作業ブランチ: `feat/dialogue-balloon-controls`
- 関連: [ADR-0002](0002-layer-model-and-caption-layout.md)、[ADR-0011](0011-balloon-dialogue-and-thumbnails.md)、[ADR-0015](0015-numeric-controls-and-glyph-fallback.md)

## 背景

吹き出し本文は枠の幅・高さに0.84倍（尖り形では0.70倍）を適用し、共通文字配置でも0.88倍を適用していた。通常形では約74%、尖り形では約62%しか改行までの長さに使えず、余白を調整する手段もなかった。また、上付きは複数行・複数列だけに適用されていた。本文を枠とは独立に上下左右へ移動する設定は、キャプションにもなかった。

## 決定

1. 吹き出し・キャプションに `textOffsetX`・`textOffsetY` を追加する。初期値は0、範囲は−30000〜30000px。横は正で右・負で左、縦は正で下・負で上。レイヤーの回転前の座標系で適用するため、回転した枠では枠の向きに沿って動く。
2. 移動量は改行・揃え方・文字サイズの計算後に本文へ加算する。枠やテール、改行位置は文字位置調整だけでは変えない。キャプションの自動サイズ追従も移動量に影響されない。
3. 吹き出しにも既存キャプションと同名の `padding` を追加する。初期値0、範囲0〜2000px。本文の各辺の余白は `padding + borderWidth / 2 + outline + max(0, thickness)` とし、残る幅・高さで改行する。固定の形状別縮小率と共通の0.88倍を吹き出しから除去する。通常の独立した台詞・効果音は既存の改行領域を維持する。
4. 吹き出しの上付きは1行・1列でも適用する。中央揃えは従来どおり中央を使う。本文に入力された改行は保持する。
5. 本文のクリップは実際の枠の内側で行う。吹き出しは既存の形状パスを使う。キャプションは枠線の内側でクリップし、文字位置調整で余白領域へ動かした本文も表示できるようにする。
6. カードと右側設定欄の両方へ、横位置・縦位置・内側の余白を数値入力と連動スライダーで追加する。移動量の刻みは0.5px、余白は既存キャプションと同じ1px。直接入力やコピーで生じた端数も保持する。移動量スライダーは画像寸法を通常範囲とし、直接入力が超えた場合は許容範囲内で広げる。独立した台詞・効果音では表示しない。
7. 保存・コピー・プリセット・Undo/Redoに新設定を含める。異なる画像へのコピーでは横移動量を幅の比率、縦移動量を高さの比率で拡縮する。プリセットも横・縦をそれぞれ画像寸法の比率で保存する。余白は既存寸法設定と同じく、コピーでは短い方の拡縮率、プリセットでは画像の短辺に対する比率を使う。
8. 旧編集データの欠損した移動量・吹き出し余白は0で補完し、旧プリセットでは適用先の設定を維持する。追加フィールドのため `PROJECT_VERSION=9` を維持する。描画方式が変わるため `RENDER_VERSION=8` とする。

## 代替案

- 文字位置調整だけを追加すると、固定余白による早い改行は解消しない。吹き出しの改行領域と余白も変更する。
- 文字位置調整で残り幅・高さも変更すると、位置を微調整しただけで改行や自動文字サイズが変わる。配置後の平行移動として扱う。
- 形状別の固定余白を残すと、利用者が枠を十分に使えない。指定した余白と輪郭幅を使い、形状の端では既存のクリップで制限する。

## 結果と制約

既存の吹き出しも改行位置が変わり、短い本文の上付きが反映される。保存済みプロジェクトの吹き出しは再確認が必要。新設定の省略時は0となり、既存キャプションの配置・自動サイズ計算は維持する。

楕円や尖り形は外接矩形の角まで本文を表示できない。端へ寄せた本文や大きく移動した本文は隠れるため、余白・文字位置・文字サイズで調整する。キャプションの収まり判定は移動前の文字寸法を判定し、移動後の全字形が表示される保証ではない。画面にもクリップの案内を表示する。

ブラウザ検証では、小数座標で文字がクリップ境界に重なるとHTML CanvasとOffscreenCanvasで境界1pxの濃淡が異なる場合を確認した。PNGの画素一致検証は本文が枠内に収まる配置で行い、枠端で隠れる動作は別の条件で確認する。既存の色・輪郭と編集保存の検証でも中央揃え・必要な余白を明示し、上付きの適用変更により文字が形状の端で切れる影響を避ける。
