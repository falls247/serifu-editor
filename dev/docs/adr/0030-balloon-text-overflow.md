# ADR-0030: 吹き出し本文のはみ出し描画

- 日付: 2026-10-16
- 状態: 採用
- 関連: [ADR-0016](0016-text-position-and-balloon-content.md)、[ADR-0028](0028-annotation-draft-import.md)

## 背景

吹き出し本文を形状パスでクリップしていたため、文字位置を枠外へ調整すると本文が欠けた。楕円や尖り形では外接矩形の角付近でも文字が隠れた。

## 決定

1. 吹き出し本文の形状クリップを外し、全形状で枠外の文字・文字輪郭を描画する。既存の折り返し、文字サイズ、文字位置、余白の計算は維持する。
2. 共通描画処理を変更し、プレビュー・OffscreenCanvas・Worker・PNGで同じ結果を使う。画像の外側は従来どおり出力範囲に含めない。
3. 自動配置の境界に、文字位置・輪郭・回転を反映した本文の領域を含める。
4. 保存フィールドは追加しない。既存プロジェクトにも適用し、描画キャッシュの `RENDER_VERSION` を13に更新する。キャプションの枠内クリップは維持する。
5. ADR-0016の決定5と結果・制約にある吹き出し本文のクリップ方針は、本決定で置き換える。

## 影響

以前は枠で隠れていた既存プロジェクトの文字も表示される。枠内に収めたい場合は文字位置・余白・文字サイズを調整する。

## 検証

- `test/annotation-drafts.test.mjs`: 文字位置・輪郭・回転を含む吹き出しの境界。
- `scripts/text-position-smoke.mjs`: 全4形状、縦書き・横書き、回転と正負の移動で文字が欠けないこと、複数行のはみ出し、OffscreenCanvas・Workerの画素一致、PNG・プロジェクト・一時保存の既存検証。
