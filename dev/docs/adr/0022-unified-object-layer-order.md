# ADR-0022: 全オブジェクトの重なり順を配列順に統一する

- 状態：採用済み
- 記録日：2026-10-11（日本時間）
- 置換対象：[ADR-0002](0002-layer-model-and-caption-layout.md) の制約付き描画順、[ADR-0009](0009-named-layer-presets.md) の吹き出しプリセットに含まれる効果音との重なり

## 背景

前面・背面操作で `page.layers` を並べ替えても、描画時に吹き出し・効果音・台詞・キャプションの種類別制約が適用されるため、効果音を任意の吹き出しの上に置けなかった。吹き出しだけは別の `sfxOrder` 設定で全効果音との関係を操作しており、オブジェクト単位の順序と一致しなかった。

## 決定

`page.layers` の先頭を最背面、末尾を最前面とし、全種類を保存順で描画する。カード一覧も上から背面→前面の順で表示する。選択判定は逆順で行い、PNG出力・原寸プレビューも同じレンダラーを使う。

- 「背面へ」「前面へ」は選択オブジェクトを1段移動する。
- 「最背面へ」「最前面へ」は選択オブジェクトを端へ移動する。
- 複数選択では選択同士と非選択同士の相対順を保持する。
- 順序変更を画像別Undo／Redoの対象にする。端での変更なし操作は履歴に追加しない。
- 新規追加・複製・貼り付けは末尾へ追加し、最前面に配置する。
- 吹き出しの背景・枠・本文は一つのオブジェクトとして移動する。

## 保存互換性

編集データのバージョンを10から11へ更新する。10以前のプロジェクトと一時保存は、読み込み時に旧仕様の実際の描画順へ一度だけ並べ替えてから各レイヤーを正規化する。旧 `sfxOrder` が `above` の吹き出しがある場合は、背面吹き出し→効果音→前面吹き出し→台詞・キャプション。ない場合は背面吹き出し→その他の元の相対順。旧データの表示を保持し、新仕様で読み直す際の再変換を防ぐ。

`sfxOrder` は新規レイヤー・保存データ・プリセットから除外する。旧プリセットの値は読み込み時に破棄する。重なり順は画像内の他のオブジェクトとの関係なので、見た目のプリセットで変更しない。

## 結果と注意点

効果音ごとに別の吹き出しの上・下を選べる。種類別の自動保護がなくなるため、台詞を吹き出しの背面に置くと隠れる。後から追加した吹き出しも最前面になるため、必要に応じて背面へ移動する。

バージョン11の保存データはバージョン10以前のアプリでは読み込めない。
