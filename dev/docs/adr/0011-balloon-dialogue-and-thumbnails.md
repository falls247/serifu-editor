# ADR 0011: 吹き出し内のセリフと編集済みサムネイル

- 日付: 2026-10-10
- 状態: 採用

## 背景

吹き出しとセリフを別レイヤーにすると、移動時に位置がずれる。編集データの読み込みではレイヤーが復元されても、サムネイル画像が元画像のままで編集結果を確認できなかった。

## 決定

吹き出しレイヤーに本文、話者、書体、文字サイズ、縦横書き、白縁、文字の太さを保持する。既存のセリフ描画処理を吹き出し形状内でクリップして使用し、枠と本文を一つのオブジェクトとして保存・複製・移動する。従来の空の吹き出しには文字設定の既定値を補い、表示を維持する。

サムネイルでは、保持している320px以内の元画像に同じレイヤー描画処理を縮小して合成する。読み込み時は合成後に表示し、編集・履歴操作・書体読み込み後は更新をまとめて再描画する。古い描画結果を世代と設定の比較で除外し、差し替えたBlob URLと一時キャンバスを解放する。編集済みと確認済みは独立した状態として表示する。

アップロード元フォルダ名は編集データと一時保存に保持する。`.serifu`は保存経路によらず`フォルダ名_YYYYMMDD_HHmmss_mmm.serifu`とする。編集済みだけの出力を識別する`_edited`は出力フォルダ・ZIPに付ける。

## 影響

吹き出し内の本文も話者別のテキスト出力に含まれる。旧プリセットの文字設定が欠けている場合は、既存レイヤーの値を引き継ぐ。サムネイルは元画像の縮小データから合成するため、原寸PNGとは縮小時の画質が異なる。

## 2026-10-11: サムネイルの順序変更と一覧の幅

サムネイルのD&Dは既存の `movePageTo` を使用し、ページ配列・ページ番号・移動先選択・保存順序を同期する。1列では上半分／下半分、複数列では左半分／右半分を挿入位置として表示し、一覧の上下端で自動スクロールする。Alt + ↑↓でも移動できる。編集内容と確認済み状態を保持し、一括処理中は移動を禁止する。ページ順の変更は画像別Undoの対象外という既存仕様を維持する。

一覧の右端をドラッグ、または境界にフォーカスして←→で幅を変更する。Shift併用は50px刻み、通常は10px刻み。幅は220〜720pxで、編集領域に640pxを残す上限を適用し、`serifu.view.v1` に記憶する。ダブルクリックで初期幅へ戻す。画面幅1000px以下では全幅表示を使い、記憶した幅はデスクトップ表示に戻ったときに再適用する。

`npm run test:thumbnail-browser` で実際のD&D、複数列、表示範囲をまたぐ移動、編集内容・確認済み状態・保存順序、一時保存の復元、自動スクロール、幅の記憶、狭い画面を検証する。

## 代替案

吹き出しとセリフを別レイヤーのまま関連付ける方式では、関連IDの保存、選択、コピー、削除の規則が増えるため採用しない。サムネイルを原寸PNGから作る方式は、表示していないページでも原寸デコードとPNG生成が必要になるため採用しない。

## 関連コードと検証

`balloons.js`、`renderer.js`、`model.js`、`presets.js`が吹き出しと文字設定を扱う。`app.js`がサムネイルの生成・更新を行い、`project-filenames.js`と`project-io.js`が保存名と元フォルダ名を扱う。

`scripts/editor-regression-smoke.mjs`で固定日時の各保存経路、吹き出しだけのWorker PNGと画面描画の一致、未マウントページのサムネイル合成、削除とUndo、ページ切替、編集データと一時保存の復元を検証する。`scripts/paged-smoke.mjs`は500ページで表示範囲を切り替えて復元を確認する。
