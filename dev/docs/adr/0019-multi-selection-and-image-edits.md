# ADR-0019: 複数選択のコピーと元画像を保持する画像編集

- 日付: 2026-10-11
- 状態: 採用
- 関連: [ADR-0003](0003-copy-and-history.md)、[ADR-0004](0004-edit-data-and-drafts.md)、[ADR-0018](0018-object-clipboard-and-edit-state.md)

## 背景

オブジェクトの選択とショートカットによるコピーは1件に限られていた。元画像を使った別パターンの編集には再読込が必要で、画像全体のクロップ・回転にも対応していなかった。

## 決定

1. プレビューのShiftクリック、一覧の見出しのShiftクリックで選択を追加・解除する。選択一式と位置調整対象の1件を区別し、全選択対象に枠を表示する。通常クリックは一覧では1件を選び、プレビューでは選択中の一式を保持して移動できる。
2. Ctrl／⌘＋Cは選択対象だけを元のレイヤー順でコピーする。Ctrl／⌘＋Vは相対位置・設定・話者を保って貼り付け、一式を選択する。画像寸法に応じた拡縮と貼り付けごとの20px移動は従来どおり。貼り付け一式は1回のUndo対象。選択一式の移動・矢印移動・Delete・複製もまとめて実行する。
3. 「元画像を削除」の右に「画像複製」を置く。元画像Blobを使った新規ページを直後に挿入し、重複しない `_copyN` の名前を付ける。オブジェクト、クロップ、回転、確認済み状態、履歴はコピーしない。複製は一覧内で行い、元フォルダへの書込みや削除権限は引き継がない。
4. LIVE PREVIEWの「画像を保存」の左にクロップ、左90度回転、右90度回転を置く。クロップはドラッグまたは現在の表示画像に対するピクセル数値で指定し、適用・キャンセルを明示する。範囲編集中の画像単体保存と回転は無効にする。
5. 元画像Blobとオブジェクトの元座標を維持し、`imageEdit` に元画像座標のクロップ矩形と0／90／180／270度の回転を保存する。描画時に画像と全オブジェクトを一緒に変換する。入力座標は逆変換し、クロップ後・回転後も選択、ドラッグ、サイズ調整を行える。矢印は表示上の方向へ移動する。
6. プレビュー、サムネイル、PNGのWorker処理とブラウザ側処理に同じ変換を適用する。PNGキャッシュのキーに画像編集を含める。JSON、高速形式、一時保存に画像編集を収録し、元画像の解像度とバイト列は保持する。
7. オブジェクトまたは画像編集が存在するときに編集済みとする。全オブジェクト削除後もクロップ・回転があれば編集済みを維持し、それらもリセットしたら未編集へ戻す。全領域のクロップ・4回の90度回転は恒等状態として画像編集を消す。履歴に画像編集と複数選択を含める。
8. 編集データを版10に更新する。旧版1〜9は従来どおり読み込み、画像編集なしとして扱う。旧アプリがクロップ・回転を黙って失うことを避けるため、版9のまま任意フィールドを追加する方式は採用しない。

## 代替案

- クロップ・回転を新しい画像に焼き込む方式では、クロップ外の画素が失われ、元画像表示と復元に別Blobや大容量の履歴が必要になる。元画像を保持する座標変換を採用した。
- オブジェクトの座標を画像編集ごとに書き換える方式では、繰り返すクロップ・回転で設定の丸めやサイズ制限が累積する。元座標を維持した。

## 結果と制約

画像編集は元画像とオブジェクトを一緒に加工し、リセットとUndoで戻せる。クロップ外のオブジェクトも保持するため、画面に見えなくても編集情報が残る。位置の数値調整と画像間コピーの拡縮は元画像の座標・寸法を基準にする。回転は90度単位。画像複製は一覧への追加であり、元フォルダ内にファイルは作らない。版10の編集データは旧アプリでは読めないため、更新後のアプリを使う。

## 検証

- `test/image-edit.test.mjs`: 全90度回転の座標・逆変換、回転後の連続クロップ、不正な矩形、編集状態と履歴、選択一式の独立コピー、両編集データ形式とPNGキャッシュ。
- `scripts/image-edit-smoke.mjs`: プレビューと一覧のShift選択・解除、別画像への一式貼り付け・繰返し・Undo／Redo、元画像だけの複製、ドラッグ／数値クロップ、回転後の選択と移動、PNGの画素、Workerとブラウザ描画の一致、サムネイル、JSON／高速形式／一時保存の復元。
- 既存の画像間コピー・プリセット・Ctrlドラッグ複製・表示レイアウト・保存・編集復元のブラウザテストで回帰を確認する。

実行結果: 単体テスト18ファイル、構文チェック、上記の新規ブラウザテストと既存6本（画像間コピー・Ctrlドラッグ・表示レイアウト・保存・編集復元・500件一覧）、静的ビルド、`git diff --check` が成功。
