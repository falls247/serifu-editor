# ADR-0009: 全レイヤー種類の名前付きプリセット

- 状態：採用済み
- 記録日：2026-10-10（日本時間）
- 実装基準：`e1d7081` からの追加

## 背景

台詞・効果音だけに対応していたプリセットを、吹き出し・キャプションにも適用し、種類ごとに設定を名前付きで再利用する。

## 決定

各カードにプリセット選択と「保存」「削除」を置く。「削除」は選択中のユーザープリセットに対して確認後に実行する。現在の設定がカスタム、または組込みプリセットの場合は非活性。削除時も配置済みオブジェクトの見た目を保持し、同じIDの参照を外す。削除対象が既定の場合だけ標準の既定へ戻す。上部の「選択中の設定を記憶」も全4種類に対応する。名前は空白を除いて1〜60文字。同じ種類・同じ名前への保存は確認後に上書きする。別の種類なら同名を使用できる。ユーザープリセットは全種類合計100件まで。

上部に種類別の既定選択と削除ボタンを置く。保存・カードでの適用はその種類の既定も更新し、次の新規追加に使用する。上部で既定を変更しても、配置済みレイヤーの見た目は変えない。既定選択の右の「×」でユーザープリセットを削除できる。組込みプリセットは削除不可。

| 種類 | 記憶する設定 |
|---|---|
| 台詞・効果音 | 従来の書体・文字サイズ・色・輪郭・太さ・漫画効果・ばらつき・ブラー・歪み・配置 |
| 吹き出し | 色・透過率・枠線・楕円の配置と寸法・回転・テールの有無と形状・効果音との重なり |
| キャプション | 背景・透過率・枠線・文字色と輪郭・書体・手動サイズ・文字方向・自動追従・余白・揃え方・配置 |

本文、話者、レイヤーID、文字ばらつきのseedは記憶しない。既存レイヤーに適用する際も保持する。適用は画像別Undoの対象。

配置X／幅は画像幅の比率、Y／高さは画像高さの比率として記憶する。吹き出し・キャプションの枠線、テール幅、文字サイズ、余白、文字輪郭は画像の短辺の比率として記憶し、コピーの拡縮方式に揃える。台詞・効果音の既存比率方式は保持する。適用先ではモデルの許容範囲に制限する。

保存先は引き続きlocalStorage `serifu.preferences.v1`。プリセット形式version 1、編集データversion 6を維持し、既存設定へ新しい種類の標準プリセットと既定選択を補完する。吹き出し・キャプションにも任意の `presetId` を追加し、JSON・一時保存から読み戻す。未登録ID・不正なプリセットは選択候補にしない。旧版アプリは新しい種類のプリセットを取り込めない。

## カードの操作配置

台詞の「男性・黒」「女性・ピンク」は見出し「男性セリフ」「女性セリフ」の右横に配置する。狭いカードでは複製・オブジェクト削除の操作を折り返す。セリフ交換の選択欄とボタンはカードから除去し、アプリのイベント経路も削除する。`model.js` の `swapText` は未使用の関数として残す。

## 代替案

- 種類別に別の保存領域を設けると、JSON・一時保存の移行経路が増える。既存の設定と読込経路を拡張する。
- 本文や話者をテンプレートとして保存する方法もあるが、今回も書式・配置のプリセットとし、本文入力を保持する。

## 結果と制約

名前付き設定を全種類で再利用でき、編集データに同梱して別のブラウザへ移行できる。ブラウザ単位・origin単位の保存制約は従来どおり。輪郭やブラーなどは適用先の寸法と許容範囲で変わるため、異なる縦横比では配置の調整が必要になる。
