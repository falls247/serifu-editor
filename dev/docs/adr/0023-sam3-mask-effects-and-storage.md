# ADR-0023: SAM3推論と非破壊マスク加工を分離する

- 状態：採用、実装検証中
- 記録日：2026-10-11
- 一次仕様：[SAM3実装SOW](../sow/SOW_20261011_sam3_segmentation.md)
- 基準main：`cf3437e8a1a494132806ca26258336712439f42e`

## 背景

SAM3で抽出した領域に画像加工を加え、推論サーバーを停止した後も編集・保存できる必要がある。既存の文字オブジェクトは文字入力・プリセット・一括コピーを前提とするため、マスクを同じ配列へ入れると既存編集に影響する。

計画の調査後に[ADR-0022](0022-unified-object-layer-order.md)が追加され、編集データ版11が文字の重なり順の変更に使用された。旧版11のアプリにマスク付きデータを渡すとマスクが欠落するため、計画の版番号をそのまま採用できない。

## 決定

- `page.maskEffects`に加工設定、`page.maskAssets`に不変のマスク素材を保持する。文字の`layers`は既存の配列順を維持し、画像加工より前面に描く。
- マスクの座標はクロップ・90度回転前の原画像座標に統一する。変形先bboxを最近傍でサンプルし、輪郭補正を適用する。
- 各加工は元画像の画素から生成する。追加順にマスク内部だけを合成し、重複部分では後の加工を優先する。確定前のドラフトは画面だけに表示する。
- ぼかし0pxも後勝ち規則を適用し、対象範囲を原画素へ戻す。ぼかしは3段のbox filter近似（小半径は1〜2段）を共通compositorで計算する。ぼかし・ピクセレートの平均はpremultiplied alphaで計算し、透明PNGの境界に黒ハローを作らない。
- 共通Canvas描画を画面・画像Worker・PNG・原寸表示・サムネイルで使用する。
- 編集データは版12、`.serifu`はコンテナ版2へ更新する。旧JSON版1〜11とコンテナ版1の読み込みを保持する。旧文字順の移行条件は版11未満のまま維持する。
- 大量の小圧縮素材が展開時に巨大化するため、保存／読込の素材bbox画素数総和をデコード前に256MiB以内へ制限する。候補ドラフトは別の上限を設定し、超過は明示エラーとする。
- マスクはbbox内の二値配列として展開する。圧縮形式はLSB-first bitpackとlittle-endian RLEの短い方。SHA-256は圧縮バイト列を対象とする。読み込み時に範囲・参照・長さ・checksumを検証する。
- JSONにはBase64、コンテナにはmanifestと分離したバイナリアセット、一時保存にはIndexedDBの圧縮Blobを保持する。履歴には素材のバイト列を複製せず、加工設定とIDだけを保存する。
- SAM3推論はWSL上のFastAPIへ隔離する。ブラウザはNodeの同一オリジン`/api/sam3/*`へ接続し、両サーバーとも`127.0.0.1`へbindする。NodeはCLIのOriginなし要求を許可するが、FastAPIのPOST／DELETEは許可されたOriginヘッダーを必須とする。HostとFetch Metadataも検査する。
- GPUジョブは直列に処理し、ページごとの最新要求のみ採用する。推論キャンセルは結果の無効化を保証する。実行中CUDAカーネルの即時停止は保証しない。
- 起動ロード・推論・アイドル解放は共通のasync GPU lockで直列化する。UIの再マウントは新しいセッションIDを発行し、古いrequestSeqとの衝突を防ぐ。
- 重みは管理者指定のローカルファイルだけを利用し、自動取得しない。GPU依存は`gpu` extraへ分離し、CIは`SAM3_MOCK=1`相当のモックとGPU不要テストを使用する。

## 公式APIの実機差分

固定upstreamのinteractive predictorはbackboneなしで生成されるため、SOW記載の`predictor.set_image`直接呼び出しは実機で失敗した。公式`SAM3Image.predict_inst`が`processor.set_image`のinference stateを予測器へ渡す経路を使用する。ポイントの前景／背景と候補修正の意味は維持する。このラッパーが提供する接続を利用し、独自の特徴量互換を推測して実装しない。

## 代替案と結果

`layers`へのマスク混在は、文字専用機能との結合が大きいため採用しない。推論ごとのクラウド送信とCPUフォールバックは確定仕様の対象外。コンテナ版1へのマスク追加は旧アプリの無言欠落を防げないため採用しない。

新形式は旧アプリでは開けない。大量マスクはbbox内の画素数に比例してRAMを使う。ピクセレート・ぼかしは匿名化を保証しない。実checkpointによる検証と実機性能は[GPU検証記録](../sam3-gpu-validation.md)に記録し、未実施を合格と扱わない。
