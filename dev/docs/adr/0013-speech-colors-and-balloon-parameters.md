# ADR-0013: セリフの文字色・輪郭と吹き出しの形状パラメータ

- 日付: 2026-10-10
- 状態: 採用
- 作業ブランチ: `feat/dialogue-balloon-controls`
- 関連: [ADR-0011](0011-balloon-dialogue-and-thumbnails.md)、[ADR-0012](0012-distressed-ink-and-balloon-effects.md)

## 背景

通常のセリフと吹き出し内のセリフは、話者に応じた黒・ピンクと白い輪郭に固定されていた。ユーザーから、文字色と輪郭の太さ・色、吹き出しの歪み・尖り型のseed、尖り型の頂点数を個別に調整する要求があった。

## 決定

1. `dialogue`・`balloon` に `textColor` と `textOutlineColor` を追加する。`textColor=null` は話者の初期色（男性 `#111111`、女性 `#ef4b91`）を使用し、指定色は話者の変更後も保持する。「話者の初期色」で自動色へ戻せる。輪郭色の初期値は `#ffffff`。
2. 文字輪郭の幅には既存の `outline` を使い、0〜80pxを許可する。0は輪郭なし。字形マスクによる文字太さ変更と通常の `strokeText` の両経路に色と輪郭を反映し、輪郭色を字形キャッシュキーに含める。
3. 吹き出しの既存 `shapeSeed` を0〜4294967295の整数としてUIへ公開する。歪み長方形ではseedをハッシュして波形の位相を変え、隣接するseedでも形状が変わるようにする。尖り型は既存の固定seed乱数を使用する。「形状を再生成」はseedの更新1回をUndoの単位とする。
4. `balloon.spikeCount` は6〜60の整数、新規の初期値は12。形状キャッシュキーに頂点数を追加する。旧データで省略されている場合は、旧方式のseedから10〜14の頂点数を算出し、従来の尖り型を保持する。内側へくぼむ二次曲線の制御点が中心を跨がないよう、曲線の深さを制限する。
5. カードと右側の設定欄で文字色・輪郭・形状パラメータを同期する。形状seedは歪み長方形・尖り型で、頂点数は尖り型で表示する。seed・頂点数の入力は整数へ丸め、範囲内へ制限する。
6. ユーザープリセットは文字色・輪郭色・輪郭幅と形状seed・頂点数を保持する。組み込みの吹き出しプリセットはseedを指定せず、新しいレイヤーのseedを使用する。旧プリセットで新フィールドが省略されている場合は適用先の設定を保持する。コピー・Undo・一時保存でも設定を保持する。
7. `PROJECT_VERSION=8`、`RENDER_VERSION=4`。JSONは1〜8、高速形式は内部プロジェクト版6〜8を読める。JSON／高速形式の保存版は `PROJECT_VERSION` を共有し、キャプションの文字色・輪郭UIも共通の色入力へ統合する。

## 代替案

- 既存 `color` をセリフ文字色へ流用: 吹き出しでは背景色に使うため、独立した `textColor` を採用。
- 話者の切替時に文字色を上書き: 指定色が失われるため、未指定の色だけ話者へ追従させる。
- seedをプリセットから除外: ユーザーが選んだ形状の再現を優先し、ユーザープリセットでは保存する。

## 結果と制約

- 新版で保存した編集データは旧アプリへ読み込ませず、新版を使用する。
- 歪み長方形のseedの解釈を変更したため、既存データの歪みの向きも変わる。
- 少ない頂点と強い尖りでは本文の描画領域が狭くなる。ボックスの拡大や文字サイズの調整が必要になる場合がある。
- 形状seedはブラシの模様にも使われるため、seedを変更するとブラシ枠線の模様も変わる。

## 検証

- 単体: 色・輪郭0・不正値の検証、旧データ補完、プリセット、異なる解像度へのコピー、Undo、6／12／24／60頂点の数、seed0と隣接seedの変化を確認する。
- ブラウザ: 通常のセリフと吹き出しの色・輪郭・文字太さ、入力欄の同期、話者切替、輪郭0、seed・頂点数・形状再生成、プリセット、PNGとプレビューの一致、JSONと一時保存の復元、OffscreenCanvasの画素一致、モバイル幅を確認する。
- 実行入口: `npm test`、`npm run check`、`npm run test:speech-browser`、既存のブラウザ回帰テスト。
- 実行結果: 単体・構文チェック、全9本のブラウザテスト、静的ビルドが成功。新機能のHTML CanvasとOffscreenCanvasの画素差は0、同じseedの再描画差も0。500件一覧の輪郭色入力の参照先を共通設定欄へ更新し、一覧・編集回帰テストを再実行して成功を確認した。
