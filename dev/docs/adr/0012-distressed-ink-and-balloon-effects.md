# ADR-0012: 印刷かすれと吹き出しの装飾をCanvasレイヤーとして実装

- 日付: 2026-10-10
- 状態: 採用
- 対象: SOW_20261010_manga_distressed_ink.md、吹き出し形状・影・ブラシ風枠線
- 作業ブランチ: feat/manga-ink-balloon-styles-20261010

## 背景

既存の筆の掠れは単独の線状マスクに限定され、文字内部の欠け・外側の飛沫や文字単位の独立した質感を十分に表現できなかった。吹き出しの旧尖形状は谷が内側に食い込み、中央の本文を侵食する懸念があった。

## 決定

1. `ink.js` の `printDistressMask()` で、文字アルファから本文・外側飛沫・透明な欠損を決定的に生成する。描画時にHTMLや外部素材へ依存しない。
2. 既存 `renderer.js` のグリフ単位パイプラインで処理し、seedとグリフインデックスを鍵に含める。欠損は最終合成へ `destination-out` で適用し、白縁・立体影も抜く。
3. 質感モード `none` のときは旧レンダリング分岐を変更しない。SFXのみ白縁0を許可する。
4. 尖形状は9周期の半径ピークを使用し、凹みは外周に限定。本文描画領域は幅・高さ各70%へ収める。角度ごとの外周・クリッピング・ヒット判定は同一幾何を共有。
5. 吹き出しの影は背景の塗りのみから落とし、既存の枠線へ影を二重に付けない。ブラシ風枠線は同じパスのシード固定3パス描画。デフォルトではどちらも旧外観を維持。
6. プロジェクトのモデル版は7へ更新。JSON 1～7と高速形式の内部版6、7を読込対象にする。プリセットから `textureSeed` を除外し、編集固有の模様を維持する。
7. キャッシュ版を更新し、メインとWorkerの共通 `draw()` を使用する。

## 採用理由・トレードオフ

- Canvasアルファ方式: 環境非依存・PNGとの再現性が高い。初回字形描画にCPU負荷が加わる。
- ランダム素材/PNGテクスチャ: 素材ライセンスとリピート表現の問題があるため不採用。
- シェーダー: 工数・互換リスクが大きいため不採用。
- 半径ベースの尖形状: 非常に狭い吹き出しでは本文が切れる可能性が残るため、70% insetとユーザーによるサイズ調整で対応。

## 検証と制約

- 単体検証: 文字透明穴・固定seed・飛沫・既存版の読み込み・吹き出しの形状／新設定をテスト。
- `npm run check` と `npm test` はGitHub Actionsで検証。
- 実ブラウザ画素比較、Worker vs メインのRGBA一致、計測10回の中央値/P95、参考画像との目視比較は別途環境準備して実施する。実測データ未取得時に達成済みとは扱わない。
- 新版編集データv7を旧アプリへ読み込ませない。

## 2026-10-10: 尖り型とブラシ枠線の外観調整

- 作業ブランチ: `fix/balloon-spikes-brush`
- ユーザー指定: 頂点をランダムに配置し、頂点間の曲線を内側へくぼませる。ブラシの粒状感を強める。
- 決定4を更新: 固定seedから10〜14個の頂点を生成し、角度間隔・半径・曲線の深さを個別に変える。頂点同士は中央側へ制御点を置いた二次曲線で接続する。角度ごとの境界は同じ二次曲線との交点から算出し、描画・文字クリップ・テール・ヒット判定へ共有する。描画のサンプルに頂点を必ず含め、尖りを保持する。形状キャッシュは64件を上限とする。
- 決定5の枠線方式を更新: 単純な3パスの重ね描きから、固定seedの7本の繊維へ変更する。枠線幅に応じた粒の大きさ、繊維ごとの欠け、太さの揺れ、4段階の濃淡を組み合わせる。欠け部分にはインクを描かず、背景・吹き出しの塗りを消去しない。荒れ0は通常枠線と同じ描画にする。
- 決定7を更新: `RENDER_VERSION=3`。保存モデルの変更はなく、既存の `shapeSeed`・`distortion`・`brushRoughness` を使う。
- トレードオフ: 尖り型とブラシ枠線を指定した既存データの外観も変わる。繊維描画は旧3パス方式より処理量が増えるため、周長方向の分割数を8192以下へ制限し、同じ濃淡のパッチをまとめて描く。
- 回帰検証: 頂点間隔・半径のばらつき、全曲線の内向き、中央領域、固定seed、境界内外のヒット判定を単体テストへ追加。ブラシの粒状の欠け、強度による変化、荒れ0、固定seed、呼出側の透明度、HTML CanvasとOffscreenCanvasの画素一致をブラウザテストへ追加。通常・荒れ50・荒れ100の比較画像を `artifacts/balloon-brush-preview.png` へ生成する。
