# ADR-0025: 等倍拡大鏡とプレビュー描画の共有

- 日付: 2026-10-11
- 状態: 採用
- 関連: [ADR-0020](0020-full-size-preview-and-numeric-ui.md)、[ADR-0024](0024-shared-mask-and-text-order.md)

## 背景

LIVE PREVIEWの一部分を等倍で確認し、確認領域のサイズをドラッグで調整したい。従来の原寸モーダルは開くたびに別のImageをデコードし、編集結果を描き直していた。

## 決定

1. 100%ボタンの左に拡大鏡ボタンを追加する。プレビュー枠内に100%固定のウィンドウを表示し、本体のドラッグで移動、右下のハンドルのドラッグで幅・高さを変える。ウィンドウの移動可能な全範囲を、元画像の表示可能な全範囲へ対応させ、上下左右の端と四隅まで確認できるようにする。枠いっぱいのサイズでもドラッグ・矢印キーで表示位置を動かす。小さい画像は周囲に余白を置く。
2. 確認ウィンドウは1個まで。別の画像の拡大鏡を開くと前の拡大鏡を閉じる。閉じるボタン、起動ボタンの再クリック、Escapeで終了し、起動ボタンへフォーカスを戻す。矢印キーで移動、ハンドルにフォーカスして矢印キーでサイズ調整、Shiftで10px刻みにする。Pointer Captureでマウス・タッチとキャンセルを処理する。
3. 拡大鏡と原寸モーダルは`preview-render.js`の1枚の原寸Canvasを共有する。マウント済み画像を再利用し、未読込の画像だけデコードする。Imageを持たない呼び出しにはsrcからの読込を維持する。未読込の書体だけ待つ。選択枠、クロップ操作枠、マスクの候補は含めない。
4. 描画の署名には元画像URL、ページID、元解像度、レイヤー、適用済み画像編集、マスク加工、マスクアセットのハッシュとサイズ、使用書体の読込世代を含める。関連しない書体の読込でキャッシュを破棄しない。マスクアセットは不変として参照を共有し、レイヤー・画像編集・マスク加工はスナップショットを取る。
5. 内容が一致すればデコード・全体描画を省略する。移動とサイズ変更では原寸Canvasの対応部分だけ描く。背景の編集変更は80msでまとめて反映する。クロップ操作中の拡大鏡は回転済みの画像全体を確認する。
6. ADR-0020の「閉じたら即座にCanvasを解放」を変更する。閉じたら表示を隠し、CanvasのRGBA容量が64MiB以下なら30秒保持する。64MiB超と準備中の閉鎖は直ちに解放する。次の利用時に解放タイマーを取り消す。世代番号で閉鎖後の古い処理による再描画を防ぐ。
7. モーダルと拡大鏡でCtrl/Cmd＋Z・Yのブラウザ標準Undo/Redoを抑止する。モーダル中でも最後に編集した背景の数値欄へ標準Undoが入力イベントを送るケースがあるため、アプリのキー処理を止めるだけでは足りない。

## 結果と制約

縮小済みのLIVE PREVIEWを引き伸ばさず、元画像の1画素をCSSの1pxで確認できる。編集を変えない再表示では再読込と再描画が不要になる。初回の未読込書体と未キャッシュの編集結果には準備が必要。開いている大画像は原寸Canvas分のメモリを使用し、閉鎖後のキャッシュ上限とは別に必要になる。

## 検証

- `scripts/full-preview-smoke.mjs`: 原寸画素一致、移動・サイズ変更・矢印キー、通常サイズと枠いっぱいのサイズで上下左右端・四隅へ到達、タッチ入力とキャンセル、編集とUndoへの追従、画像切替、モバイル、モーダルとの共有、再表示時のデコード・全体描画0回、準備中の閉鎖と解放、既存の倍率・フォーカス・PNG一致・数値精度。
- `scripts/preview-layout-smoke.mjs`: 27条件の列幅・縦横比・サイドバー・モバイル表示。
- `scripts/mask-render-smoke.mjs`、`scripts/mask-order-smoke.mjs`: クロップ・4方向の回転・マスクと文字の合成順・穴・透過・候補の除外・Workerと原寸モーダルの画素一致。
- レンダラー単体テスト、構文チェック、静的ビルド、`git diff --check`。

再表示の計測例: 1600×1000pxのテスト画像で約18ms。画像のデコードと全体描画はともに0回。初回表示の速度や他の画像・端末で同じ時間を保証する値ではない。
