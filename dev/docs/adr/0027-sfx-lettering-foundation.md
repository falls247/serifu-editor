# ADR 0027: SFX文字単位編集の段階導入

状態: 一部実装・全113要件の受入は未完了

## 採用した設計

1. SOWのP1〜P3の基礎モデルを src/sfx-lettering-model.js と src/sfx-stroke-geometry.js へ分離し、PROJECT_VERSIONを14に更新。旧版JSONと、明示的に編集モードへ入っていないSFXは旧レンダラーで描画。
2. layer.textが正本。grapheme indexで編集状態を紐付け、改行は描画対象から除外。位置・同字・リセットの継承規則と決定論的LCSを使う。保存データの数値上限と参照整合性を検査する。
3. 2個以上連続した長音記号は1本の曲線として表示。始終点と線幅点、端点形状、文字へのアタッチの原型を採用。単独の長音記号は通常のフォント文字。
4. 旧SFXの変換は明示的な編集開始時のみ。既存Undo/Redoのcheckpointで戻せる。レイヤー間のZ順やキャンバスのピクセル寸法は変更しない。
5. 新モジュールを開発サーバー・静的ビルド・テスト用Pagesサーバーの配信対象へ追加した。

## 残課題と安全上の制限

- P3: 複数runの選択、端点形状/分離、制御点位置と始終点線幅の数値編集を追加。ただしキャンバス上の制御点ドラッグ、線幅点の追加削除、幾何分割・結合、実インク輪郭への高精度アタッチは未実装。端点追従は文字中心とサイズによる近似。
- P4: 文字グループの自動重なり判定、合成外周輪郭、固定メンバー管理とグランジ連動は未実装。
- P5: 複数グリフ一括操作、矩形/なげなわ、モバイル用の操作ハンドル/ルーペ、デザインテンプレート管理とJSONインポートは未実装。
- P6: JSON/.serifuのv14へprojectId/pageIdを保存し、ファイルから再読込して検証する処理を追加。ただし「編集データを現在の一覧へ追加」は従来どおり取込として扱う。プロジェクト全置換UI、同一IDの内容比較/三択競合、プロジェクト別履歴は未実装。
- P7: IndexedDBの5分間隔5世代履歴、素材の参照共有とガーベージコレクション、複数タブのfencing排他は未実装。既存IndexedDB v2のdrafts.currentを引き続き使用し、移行や破壊的DB変更を行っていない。
- P8: SOW全シナリオ、端末別手動検証、性能ベンチマークと新旧画像ピクセル比較の完全実施は未完了。

**注意:** 現在の自動保存は旧方式のため、プロジェクトIDごとの履歴・排他・障害時復元のSOW要件を満たさない。安全な移行を検証するまで、唯一のバックアップとして利用しない。serifuファイルを外部保存する。

## 検証

- src/sfx-lettering-model.js および src/sfx-stroke-geometry.js のNode単体テスト。
- scripts/sfx-lettering-smoke.mjs でグリフ操作・本文同期・Undo/Redo・JSONのブラウザスモーク。
- 既存チェックはGitHub Actions「Checks」から当該SHAの結果を参照。失敗が残る場合は完了扱いとしない。
