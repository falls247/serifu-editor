# ADR-0034：マスク加工カードのスライダーと元マスク比のサイズ指定

- 日付：2026-10-25
- 状態：採用。

## 背景と判断

マスク加工カードの既存数値設定へスライダーを追加する。ブロック幅、ぼかし半径、輪郭補正、位置、幅、高さは既存の範囲・整数値を維持し、方式に応じた非表示を数値欄とスライダーの組に適用する。

元マスク素材のbbox（Bounding Box：マスクを囲む矩形）の幅・高さを100%として倍率調整する。既存の`x/y/w/h`を正とし、倍率は保存しない。保存形式は版15、元マスクのバイト列とchecksumは変更しない。表示・PNG・Workerは既存の変形経路を利用する。

倍率変更は現在の中心基準、元素材の縦横比で実行する。画像全体に収まる倍率と100Mpx上限へ制限し、位置は内側へ移動して収める。寸法の整数丸めによる最大1px程度の比率差は許容する。下限1%、寸法下限1pxとする。100%で元寸法に戻すが、移動済みの位置は維持する。

幅・高さを個別変更したときは全体倍率が一意に決まらないため、サイズ欄は元の幅に対する割合と明記し、注記へ幅・高さの両割合を表示する。その後サイズ欄を操作すると元の縦横比へ戻す。隠れた倍率フィールドを追加したり、幅から勝手に高さを推定して既存データを変更したりしない。

元素材から毎回寸法を計算するため、スライダー操作でマスク素材を再サンプリング・再圧縮しない。輪郭補正、ブロック幅、ぼかし半径はpx値を維持する。

## 操作と制約

数値とスライダーは同じ正規化・履歴・変更通知を通す。連続inputを1操作として記録し、change／focusoutで区切る。プレビューの移動・変形、Undo/Redo、カード再マウント、保存復元でも全コントロールの値と可動範囲を更新する。

大きなマスクのスライダー操作では既存の同期描画コストが残る。描画方式や品質は変更しない。画像端での拡大は位置も変わり得るためカードと説明書へ明記する。省メモリ化のSOWとは独立したUI改修。
