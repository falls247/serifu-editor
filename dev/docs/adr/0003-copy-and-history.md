# ADR-0003: 画像サイズに応じたコピーと画像別の履歴を採用する

- 状態：採用済み（既存実装の事後記録）
- 記録日：2026-10-10（日本時間）
- コード基準：`b721ad78a7c658f23b83a0da1f6ed13c950c9696`

## 背景

複数の画像を連続して編集し、選択した文字や全レイヤーを別の画像へ再利用する。横長から縦長への貼り付けにも対応し、カットや一括貼り付けを1回のUndoで戻したい。入力欄の通常の文字コピーとプレビューのレイヤーコピーも区別する必要がある。

## 決定

選択レイヤー用と画像全体用の2つのクリップボードをアプリのメモリに持つ。OSクリップボードに画像や編集JSONを書き込む方式ではない。`structuredClone` でコピー時の状態と元画像サイズを保存し、その後の編集や元ページの除去に影響されないスナップショットにする。

プレビューにフォーカスがありレイヤーを選択中のCtrl／⌘+C/Vは選択レイヤーを操作する。入力欄では通常の文字コピーを維持し、IME変換中はショートカット処理を避ける。一括コピー・カット・ペーストはボタンから画像全体のレイヤーを操作する。

## 異なる画像への拡縮

元画像サイズを `Ws × Hs`、対象を `Wt × Ht` とし、`sx=Wt/Ws`、`sy=Ht/Hs`、`s=min(sx,sy)` を使う。

| 属性 | 拡縮方法 |
|---|---|
| `x`、`w` | `sx` 倍 |
| `y`、`h` | `sy` 倍 |
| 文字サイズ、インクの太さ、白縁、通常ブラー・残像 | `s` 倍 |
| 方向別ブラー `blurX`／`blurY` | それぞれ `sx`／`sy` 倍 |
| 吹き出しのテール先端 | Xは `sx`、Yは `sy` 倍 |
| 吹き出しの枠線・テール幅 | `s` 倍 |
| キャプションの手動文字サイズ・枠線・余白 | `s` 倍 |
| 色、回転、透過率、各効果の割合、先細り変化率、揃え方、自動追従 | そのまま保持 |

寸法や効果量は各パラメーターの許容範囲にクランプする。新しい `id` を発行するが、字形ばらつきの `glyphSeed` は保持する。文字の比率は同じ倍率で縮小し、ボックスの位置・大きさは画像の縦横比に追従する。

一括貼り付けは既存レイヤーへ追加し、位置のオフセットは付けない。選択レイヤーの貼り付けは重なりを見分けられるように20pxずつずらす。選択レイヤーの台詞／効果音では `presetId` を外し、コピー済みの書式を保持する。一括コピーはプリセット参照も保持する。

## 履歴と編集済み判定

各画像に `undo`／`redo` を持ち、`layers`、`done`、`edited` をJSONスナップショットとして保存する。Undo側は最大100件。カット、画像全体の貼り付けは各1チェックポイントで、元画像と対象画像の履歴は独立する。Undoしてもメモリ内のクリップボードは戻さない。

入力やドラッグは一続きの操作をまとめ、実際の変更時に履歴を作る。選択だけではRedoを消さない。編集のチェックポイントは `edited=true`、`done=false` にする。Undo／Redoで両フラグも復元し、「編集済みだけ保存」の対象を戻せるようにする。

`done` は利用者の確認済み状態で、編集した事実とは別。文字をすべてカットした画像も編集済みになり得るため、保存対象を `layers.length` だけで判断しない。画像読込時はレイヤーがあるか保存済みの `edited` がtrueなら編集済みとして扱う。

## 代替案と比較

- 元のピクセル位置をそのまま使うと、画像サイズが違う際に画面外へ出やすい。画像比で位置とボックスを変換する。
- 全属性を縦横別に引き伸ばすと文字の見た目が大きく変わる。文字や線の太さは小さい方の倍率を使う。
- グローバル履歴は別画像の作業まで巻き戻す。画像単位の履歴を採り、コピー元・先をそれぞれ戻せるようにする。

## 結果と制約

クリップボードと履歴はページ再読込で失われ、JSONや一時保存に含まれない。元ファイルの削除や出力フォルダへの書込みもUndo対象外。画像間コピーは構図の意味を認識しないため、貼り付け後の位置・折返し確認は必要。
