# 操作説明書への影響記録

## 2026-10-25：SAM3推論失敗の診断ログ

- 変更対象：`backend/app/engine.py`。汎用推論エラーのサーバーログへ例外本文・トレースバック・検出モード・画像寸法・ポイント数・スレッドIDを追加する。画像本体、プロンプト、ポイント座標は記録しない。
- 操作説明書への影響なし：画面表示、APIのエラー応答、検出操作、保存方法、利用条件は変更せず、既存の推論失敗時にサーバー側で失われていた診断情報だけを残すため。

## 2026-10-25：SAM3再ロード後の推論dtype不一致の修正

- 変更対象：`backend/app/engine.py`。画像特徴抽出からテキスト・ポイント・候補修正の推論全体を、実行スレッド内で明示的なCUDA BFloat16 autocast（自動精度変換）に入れる。モデル構築スレッドに残る暗黙の設定へ依存しない。
- 操作説明書への影響なし：解放・再ロード後も既存の検出操作が成功するよう内部の精度変換を修正する。画面、操作手順、無操作解放の条件、モデルの重みdtype、保存形式、エラー時の利用者向け対処は変わらないため。通常表示・FOCUS・原寸表示で同じバックエンドを利用し、マウス・タッチ・キーボードの入力処理にも変更はない。
