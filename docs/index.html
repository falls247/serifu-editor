SERIFU EDITOR / OPERATION MANUAL

画像に、声を。
編集の手引き。

画像を開き、言葉を置き、仕上がりを保存する。
はじめての1枚から、複数ページの連続編集まで。

まず使ってみる ↓保存方法を確認する ↓キー操作を探す ↓

対象：2026年10月18日時点の実装 · 通常の編集はブラウザ内で処理 · SAM3の新規検出はローカル起動時のみ

01最初の1枚を仕上げる

  1. 画像を開く上部の「画像を追加」で画像を選ぶ。フォルダ単位なら「フォルダを開く」。手元の画像なしで試す場合は「3枚のサンプルで試す ↗」を使う。
  2. セリフを書く画像の中央列で「＋ 男性」か「＋ 女性」を押し、カードの本文欄へ入力する。新規セリフは縦書き。話者はカード見出しで切り替えられる。
  3. 位置と大きさを整える右のプレビューで文字をドラッグ。選択枠の右下でサイズ、上の丸で回転を調整する。書体・文字サイズ・文字方向は下の設定欄で変更する。
  4. 画像と編集データを保存する「画像を保存」でこの1枚をPNG出力する。あとで直すために、上部の「編集データを保存」から.serifuも保存する。

複数枚をまとめて保存する場合は「一括保存」。PNGと再編集用データを、新しいフォルダまたはZIPにまとめる。保存方法の違いを見る。

02画面の見方

各画像の編集画面は3列構成。下へスクロールすると次の画像を続けて編集できる。狭い画面では各列を縦に並べる。

01 / ORIGINAL元画像

元の画像を確認。画像の除外・複製と、SAM3のマスク検出。

02 / WORDSセリフ・効果音

オブジェクトを追加し、本文・色・装飾・プリセットを編集。

03 / LIVE PREVIEW仕上がり・配置

ドラッグで位置を調整。数値設定、クロップ、回転、PNG保存。

上部メニューには読み込み・保存・既定プリセット・自動保存がある。左の「ページ一覧」はサムネイルからの移動と絞り込みに使う。中央のカードやプレビューを選ぶと、そのオブジェクトの設定が開く。

細部を確認する

  • 100%：原寸プレビューを別画面で表示。10〜200%に拡縮し、ドラッグで表示位置を移動する。「閉じる」かEscで戻る。
  • FOCUS：枠の大きさを固定して拡大編集する。倍率100%は元画像1pxを画面1pxで表示。倍率欄は数値入力か上下ドラッグで変更でき、手のひらボタンで表示位置を動かす。
  • 拡大鏡ボタン：一部分を等倍で確認する。拡大鏡の位置とサイズはドラッグで調整する。

03画像とページの管理

「画像を追加」は複数選択に対応。「フォルダを開く」はフォルダ内の画像を読み込む。画像ファイルをページ一覧へドロップしても追加できる。新しく読み込む画像はファイル名の数字を考慮した順に並ぶ。

ページ一覧と各画像の見出しで使う操作
操作使い方
ページの移動サムネイルをクリック、または上部の矢印・画像選択欄で移動する。
絞り込み「未編集のみ」「編集済みのみ」「未確認のみ」「確認済みのみ」を選ぶ。「すべて」で解除する。
並べ替えサムネイルをドラッグ、またはフォーカスしてAlt＋↑／↓。画像見出しの「ページ移動↑／↓」も使える。「ページの後へ」に現在の番号を指定して「移動」を押すと、そのページの直後へ移動する。0は先頭。
確認済みにする「編集完了・次へ」で確認済みにして次へ進む。確認済みと編集済みは別の状態。
表示を軽くする表示件数を「50件ずつ」か「100件ずつ」にする。表示範囲やフィルターを変えても、一括保存の対象をその範囲だけには絞らない。
一覧の大きさサムネイル倍率は50〜200%。一覧右端をドラッグして幅を調整し、ダブルクリックで初期幅へ戻す。「サムネイルを非表示」で隠す。
画像複製元画像だけを一覧内に複製する。文字などの編集内容は引き継がない。
一覧から外すアプリの一覧から除外する。元ファイルは残るが、そのページの未保存の編集は失われる。

「元画像を削除」は実ファイルの完全削除。ファイル名の確認後に削除し、ゴミ箱には移動しない。Undoでは戻せない。「フォルダを開く」で直接接続し、削除APIが使える画像だけが対象。画像追加・サンプル・編集データから読み込んだ画像では使えない。

画像別のJSON下書きを取り込む

同じフォルダにimg001.jpgとimg001.jpg.jsonを置き、「フォルダを開く」で読み込む。通常の画像追加やドラッグ追加では下書きを取り込まない。

{
  "schemaVersion": 1,
  "imageFile": "img001.jpg",
  "annotations": [
    { "type": "dialogue", "speaker": "female", "text": "こんにちは" },
    { "type": "speech_bubble", "text": "吹き出しの本文" },
    { "type": "caption", "text": "その日のこと。" },
    { "type": "sound_effect", "text": "ドン" }
  ]
}

セリフのspeakerはmaleかfemale。既定プリセットで右上から左、次に下段へ自動配置する。収まらなければ縮小し、限界を超えた分は画像外に残して警告する。位置とサイズを確認してから保存する。不正な下書きがあっても画像は読み込む。元画像・下書きJSONは変更しない。この形式は「編集データを追加」で開くプロジェクト形式とは異なる。

04セリフと文字の書式

「＋ 男性」「＋ 女性」でセリフを追加する。初期色は男性が黒、女性がピンク、輪郭は白。色と輪郭は変更できる。セリフ追加時に吹き出しは付かない。

  • 本文欄に直接入力する。入力欄の高さは明示的な改行に合わせて伸び、長い1行は横スクロールする。プレビューの折り返しは配置幅・高さにも依存する。
  • カード見出しの「男性」「女性」で話者を変更する。「文字色」「文字の輪郭色」「文字の輪郭の太さ」で見た目を調整する。輪郭の太さ0で輪郭を消す。
  • 「文字方向」で縦書き／横書きを選ぶ。縦書きの句読点は文字枠の右上に配置する。「改行位置」の上付き／中央揃えで複数行の揃え方を変える。
  • 「文字の太さ（px）」は−10〜30。0が書体の標準、正で太く、負で細くする。輪郭や文字サイズとは別の設定。細くしすぎると細線が消える。

書体を選ぶ

右側の「書体」から、ゴシック・明朝・手書き・漫画向けなどを選ぶ。選んだ書体の読み込み後にプレビューが更新され、PNG保存も読み込みを待つ。書体にない文字は端末の代替書体で表示する。

「激筆 SFX」はかな・英大文字・数字・記号向けで、漢字と英小文字は代替書体になる。「851チカラヨワク」は「手書き・丸文字」から選ぶ。ローカルで書体がない場合の準備方法は困ったときはを参照。

書体の種類と同梱ライセンス

同梱19書体と端末のゴシック・明朝を選べる。漫画向けは激筆 SFX、Dela Gothic One、Reggae One、筆文字はYuji Boku・Yuji Mai・Yuji Syuku、手書きはKlee One・Yomogi・851チカラヨワクなど。

Google Fonts由来の17書体には各OFLライセンスを同梱する。激筆 SFXはHIDEOUT作・CC0 1.0。851チカラヨワクは8:51:22 pm作で、作者の規約に従う。フォントを準備・ビルドした環境ではassets/fonts/に各ライセンス・規約を収録する。

05吹き出し

「○ 吹き出し」で追加する。本文は同じカードに入力でき、空欄のまま背景だけにも使える。話者・書体・文字色も変更できる。初期状態は白・25%透過（不透明度75%）・黒枠・テールなし。

  1. 右の「吹き出し形状」で楕円・歪み長方形・尖り形・多角形などを選ぶ。形状を変えても位置・大きさ・本文を保持する。
  2. 多角形は頂点数3〜60。「頂点数をランダム生成」で別の頂点数に変える。歪み度0%は均等な多角形。「形状を再生成」は同じ頂点数で形を変える。
  3. 塗り色・透過率・枠線色・枠線の太さを調整する。枠線0で枠を消す。「影を付ける」で影の色・濃さ・ぼかし・ずれを指定でき、「枠線の描き方」のブラシ風でラフな縁取りにできる。
  4. 「テールを追加」をオンにすると、水色の先端をドラッグできる。先端の座標・付根の角度・幅は数値でも調整できる。
  5. 本文だけ動かす場合は「文字の横位置」「文字の縦位置」を使う。横は正で右、縦は正で下へ移動する。「内側の余白」で折り返しまでの長さを調整する。

吹き出しの本文は枠外にも表示する。画像の外側はPNGに出力しない。枠内へ収めたい場合は、文字位置・余白・文字サイズを調整する。

06キャプション

「▭ キャプション」でモノローグや説明用の長方形ボックスを追加する。本文とボックスを一つのオブジェクトとして移動できる。初期状態は白背景・25%透過・黒枠・黒文字・縦書きで、本文は左右上下とも中央揃え。

  • カードで本文・文字色・文字の輪郭・背景色・背景の透過率・枠線を編集する。右側で書体・文字方向・位置・ボックス寸法・回転を調整する。
  • 「左右の揃え方」「上下の揃え方」で位置を指定する。「文字の横位置」「文字の縦位置」では、ボックスを動かさずに本文だけずらせる。
  • 「文字サイズをボックスに合わせる」は初期オフ。オフならボックスのサイズを変えても手動の文字サイズを保つ。本文はボックス内で折り返し、はみ出す部分は切り取る。
  • オンにすると本文・書体・方向・余白・枠線に合わせ、収まる文字サイズを自動計算する。オフに戻すと手動のサイズへ戻る。最小サイズでも収まらない場合は、ボックスを広げるか、本文・余白を減らす。

07効果音・文字単位編集

「✦ 効果音」で追加し、本文と書体を選ぶ。まずプリセットで近い表現を選び、必要な項目を調整すると作りやすい。

設定表現と調整
漫画エフェクト立体・集中線・スピード・震え・先細りなど。「なし」は漫画装飾を外すが、別に指定したブラー・掠れ・歪みは残る。
先細り入力順に文字を小さくする。基準100px・変化率10%なら100→90→80px。最小8pxまで。改行後も順番を続ける。
ばらつき文字サイズのばらつきと左右のズレを調整する。0で追加のばらつきを消す。保存・再読込で模様は変わらない。
ブラー・筆表現縦横のブラー、滲み、文字の芯、輪郭の荒れ、筆の掠れ、ハネ・払い、残像、傾きや縦横倍率を組み合わせる。
かすれ印刷「インク質感」の「かすれ印刷・荒れインク」を選び、強さ・擦れ筋の長さと方向・飛沫量を調整する。欠けは透明。「模様を再生成」で模様を変える。

1文字ずつ形を整える

  1. 効果音カードで「文字単位編集」を押す。
  2. 文字を選び、移動・回転・倍率・傾き・書体・色・輪郭を調整する。Shiftで複数選択、Altで重なった背面を選ぶ。
  3. 詳細パネルで矩形／なげなわ選択、共通中心での一括変形、位置・変形・外観ごとのリセット、4案の配置比較を使う。
  4. 選択文字はCtrl／⌘＋C・V・Dやドラッグでコピー・複製できる。別の効果音への貼り付けは貼り付け先の外観を使い、本文も更新する。
  5. 「文字編集を終了」か、入力欄の外でEscを押して通常の編集へ戻る。
長音の曲線・テンプレート・本文の変更

連続する「ー」は編集開始後に曲線として調整できる。曲線点・太さ点をドラッグし、点の追加削除、端点の接続／分離、長さロック、端の形状、線幅の補間を指定する。形状・太さ・見た目だけの部分コピーも使える。単独の「ー」は通常の文字として扱う。

合成外周は重なりに応じて生成し、メンバーを手動で固定できる。テンプレートはブラウザ・プロジェクト・JSONで管理し、本文とページ上の絶対位置を変えず、文字数が違う効果音にも適用できる。

文字単位編集を始めた効果音の本文を変更すると、位置／文字一致／リセットから継承方法を選ぶ。本文欄でEscは変更取消、Ctrl／⌘＋Enterかフォーカス移動で確定する。

不足する書体は代替書体かアップロードを選べる。アップロード書体は現在のセッション内だけで有効で、編集データにはファイルを同梱しない。再開時には同じ書体を用意する。

タッチ操作には大型ハンドル・長押しルーペ・2本指ズーム／パンを用意している。端末により操作感は異なる。画像外の文字・線は警告され、編集データには残るがPNGでは画像端で切り取る。

08配置・複製・重なり

プレビューで対象を選び、ドラッグで移動する。Shiftを押しながら選ぶと複数選択できる。右下の角でサイズ、上の丸で回転を調整する。X/Y・配置幅・配置高さ・回転は数値でも指定できる。

コピーと複製

  • 選択した対象：Ctrl／⌘＋Cでコピーし、貼り付け先のプレビューを選んで同＋V。書式と配置を保持し、別解像度では拡縮する。貼り付けのたびに少しずつ位置をずらす。
  • ドラッグ複製：Ctrl／⌘を押しながらドラッグする。さらにShiftを押すと元の対象を通る水平・垂直ガイドに沿う。クリックだけでは複製しない。
  • 画像内の文字をまとめて：「文字を一括コピー／カット」を押し、貼り付け先で「文字を一括ペースト」。セリフ・効果音・吹き出し・キャプションが対象で、マスクは含まない。既存の文字に追加する。
  • 次の画像へ：「文字を次の画像へ複製 →」で、次の画像のサイズに合わせて文字を追加する。

コピー内容は同じタブ内で再読込まで保持する。元をあとで変更してもコピーは変わらず、繰り返し貼り付けられる。縦横比が異なる画像では折り返しや収まりが変わるため、貼り付け後に確認する。

前後関係と取り消し

右の「背面へ／前面へ／最背面へ／最前面へ」で重なりを変更する。マスク・文字・吹き出しは共通の順序で扱い、一覧では上が背面、下が前面。前面のマスクは文字も覆う。

「戻す」「↷」で画像ごとの編集を取り消し・やり直しできる。複製や一括貼り付けは1回分として取り消す。カットと貼り付けを戻す場合は、それぞれの操作を行った画像で戻す。

09プリセット

  1. セリフ・効果音・吹き出し・キャプションを選び、書式と配置を整える。
  2. カードの「保存」か、上部の「選択中の設定を記憶」で名前を付ける。
  3. カードの選択欄で適用する。上部の種類別の「既定」で、新しく追加する対象にも使える。

プリセットは書式と配置を保存し、本文・話者は保存しない。画像解像度が違う場合は配置や文字サイズを拡縮する。同じ種類・同じ名前は確認後に上書きする。

カードのプリセット欄の「削除」か、上部の既定選択の右の「×」でユーザープリセットを削除する。配置済みの見た目は保持し、組み込みプリセットは削除できない。プリセットは同じブラウザに保存し、編集データにも含める。

10画像加工・SAM3

クロップと回転

プレビュー上部の「クロップ」を押し、ドラッグで範囲を選んで「適用」。枠内で範囲を移動し、辺や角でサイズを調整できる。X/Y・幅・高さは回転後の元画像のピクセルで指定する。「左回転」「右回転」は画像全体を90度ずつ回転する。

「クロップ・回転をリセット」で元の範囲と向きへ戻す。元ファイルは上書きしない。PNGはクロップ・回転後の解像度で保存する。

SAM3で領域を指定する

SAM3の新規検出にはGPU対応のローカル起動が必要。通常のブラウザ内編集に加え、元画像を自分のローカル推論サーバーへ送って処理する。公開版では新規検出できないが、保存済みマスクは編集・出力できる。

  1. 元画像の下のSAM3カードでテキストを入力し、「検出」を押す。Enterでも検出できる。日本語変換の確定中は実行しない。
  2. 必要に応じて前景・背景ポイントで領域を指定する。番号・色・信頼度を見ながら候補を選ぶ。複数選択も可能。
  3. 加工方法を選び、プレビューで確認して「OK」で確定する。入力変更後は最新の検出結果を待つ。確定前の仮加工はPNG・編集データへ保存しない。
  4. 確定したマスクのカードでピクセレート・ぼかし・黒塗り・白塗り、輪郭補正、表示、X/Y/W/Hを変更する。プレビューでは移動と8方向のリサイズができる。

新規検出はPNG・JPEG・WebP、30MiBかつ40Mpx以下が対象。GIF・AVIF・アニメーション画像の推論は使えない。モデルやサーバーの準備はREADMEの起動手順を参照。

ピクセレート・ぼかしは匿名化を保証しない。マスクの確定後は保存画像も確認する。マスク素材は編集データに含まれ、復元後は推論サーバーなしでも再編集できる。

11書き出しと再編集

目的に合わせて保存方法を選ぶ
操作保存するもの
画像を保存その画像だけを合成済みPNGにする。選択枠は含めない。保存先はブラウザのダウンロード設定に従う。再編集用データは別途保存する。
一括保存全画像のPNGと編集データを保存する。選んだ親フォルダの中に日時・ID付きの新規フォルダを作る。フォルダ保存非対応の場合はZIPをダウンロードする。
編集済み画像一括保存文字などを編集した画像だけをPNGと編集データに保存する。画像を開いた・選んだ・確認済みにしただけのページは対象外。
編集データを保存画像・文字・マスク・配置・プリセットなどを1ファイルにまとめる。初期形式の.serifuを推奨。上部の「保存形式」でJSONも選べる。
テキストを保存女性／男性／全台詞／キャプション／効果音／全本文から選び、全ページを現在の順序でTXT保存する。台詞は1件ごとに「」で囲む。空の本文は省く。

一括PNGの名前はp01_元の名前.pngのようにページ順の番号を付ける。桁数は全体の枚数に合わせ、編集済みだけ保存する場合も全体の番号を保つ。PNGは画像の解像度を保ち、クロップ・回転があればその結果の寸法になる。

保存した編集を再開する

  • 「プロジェクトを開く」：現在の一覧を保存ファイルの内容に置き換える。現在の作業を残したい場合は先に編集データを保存する。
  • 「編集データを追加」：保存ファイルの画像と編集を、現在の一覧へ追加する。
  • 同じプロジェクトでファイルと自動保存の内容が異なる場合は、ファイル・自動保存・別プロジェクトのどれで開くか選ぶ。

PNGだけでは文字や吹き出しを個別に再編集できない。保管・端末移行には.serifuも残す。旧形式の編集データは読み込めるが、新しい形式を古いアプリで開く用途には使わない。JSONへの切り替えでも旧版向けには変換しない。

一括処理を中断する

上部の進捗欄で処理段階・件数・失敗・経過時間を確認し、「中断」で残りを止める。画像追加の中断では追加済み画像を残し、フォルダ保存の中断では出力済みファイルを残す。ZIPはダウンロード開始前なら中断できる。通常のダウンロードは開始後にアプリから取り消せない。

保存失敗や中断時は、画面下部の結果と保存済み枚数を確認する。フォルダには途中までの出力が残る。元画像は上書きしない。

12一時保存と復元

「一時保存」は画像と編集をブラウザ内に保存する。自動保存は初期オン。編集の確定後に最新状態を保存し、設定した周期でも確認する。復元用の履歴は変更がある場合に原則5分間隔、最大5世代を残す。

  1. 再読込後は「保存した編集を復元」で作業へ戻る。
  2. 「保存プロジェクト管理」ではプロジェクトと世代を選んで復元・削除でき、保存容量も確認できる。
  3. 「一時保存を消去」は対象プロジェクトの最新状態だけを消す。履歴や別プロジェクトは残す。

同じプロジェクトは1タブだけ編集でき、ほかのタブは閲覧専用になる。編集タブを閉じたあとなどは、閲覧タブで明示的に操作すると、最新状態を再読込して編集を引き継ぐ。別のプロジェクトは独立して保存される。

一時保存は同じブラウザ・同じサイト内の保存。サイトデータ削除で失われる。公開版とローカル版、ポートが違うローカル版では保存先が別になる。移行には編集データを保存して持ち出す。容量不足で自動保存が止まったら、ファイルに退避して保存領域を整理し、手動保存の成功を確認する。

13ショートカット

Windows／LinuxはCtrl、Macは⌘。まずプレビューの対象を選ぶ。入力欄の編集中やIME変換中は、オブジェクト操作のキーを適用しない。

キー・操作動作
↑ ↓ ← →選択対象を1px移動。Shift追加で10px。
Ctrl／⌘＋C・V選択オブジェクトをコピー・貼り付け。文字単位編集では選択文字が対象。
Ctrl／⌘＋ドラッグ複製して移動。Shift追加で水平・垂直方向に沿って複製。
Ctrl／⌘＋Z現在の画像の編集を戻す。Shift追加でやり直す。
Deleteプレビューにフォーカスがあるとき選択対象を削除する。Undoで復元可能。元画像ファイルの削除とは別。
F／B選択対象と同じ種類のプリセットを次／前へ切り替える。
C／U文字の改行位置を中央揃え／上付きにする。吹き出し選択中のCは楕円への変更。
C R V M吹き出し選択中：楕円／歪み長方形／尖り形／多角形へ変更する。
E吹き出しの形状を順に切り替える。
Ctrl／⌘＋D効果音の文字単位編集で、選択文字を複製する。
Alt＋↑／↓サムネイルにフォーカスして、そのページを前／後へ移動する。

14困ったときは

フォルダへ直接保存できない

直接のフォルダ保存と元画像削除には対応ブラウザのFile System Access APIが必要。PC版Chrome／EdgeのlocalhostかHTTPSで利用する。非対応の場合、一括保存はZIP、単体保存は通常のダウンロードになる。ZIPは全体4GiB未満・最大65,535ファイルまで。大きい作業は分割する。

文字が見切れる・小さくなった

文字サイズ・配置幅・配置高さ・余白を確認する。キャプションで自動追従がオンなら、ボックスに合わせて文字が縮む。吹き出しの本文は枠外に表示するが、キャプションの本文は枠内で切り取る。画像外の部分はどちらもPNGに含めない。

想定した書体にならない

書体の読み込み状態と、その書体に使いたい文字があるかを確認する。ローカルで同梱書体がない場合はリポジトリのルートでnpm run fontsを実行して再読込する。アップロード書体は再起動時に再度用意する。端末の代替書体は環境によって見た目が異なる。

編集済みだけ保存すると画像が抜ける

確認済みは編集済みとは別。画像の読み込み・選択・「編集完了・次へ」だけでは編集済みにならない。最初の編集をUndoで戻すと未編集へ戻る。文字を削除した結果、元画像だけに見えるページも編集済みになり得る。全画像が必要なら「一括保存」を使う。

一時保存が見つからない

保存したブラウザ・サイト・ポートで開いているか確認する。別環境には.serifuを移して「プロジェクトを開く」。復元した画像は元フォルダへの接続を持たないため、「元画像を削除」は使えない。

SAM3で検出できない

公開版やnpm startだけの起動では新規検出できない。READMEのGPUセットアップを済ませ、npm run devで起動する。モデルの場所、入力形式と画像サイズ、カードのエラー表示を確認する。

動作が重い・出力が途中で止まる

表示件数を減らし、大量・高解像度画像は分けて編集する。強いブラーや極端な拡大も負荷が増える。保存途中に止まった場合は結果表示と出力済みファイルを確認する。PNGは静止画で、GIFの動きやEXIFなどの元画像のメタデータは引き継がない。高度な縦組み約物・ルビには未対応。
