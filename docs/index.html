Serifu Editor / 利用者向けドキュメント

操作説明書

この説明書では、画像の読み込み、文字や吹き出しの編集、保存・復元の手順を説明します。

対象アプリ
Serifu Editor
対象日
2026年10月18日時点の実装を対象としています。
利用環境
公開版・ローカル版でご利用いただけます。SAM3の新規検出には、GPUに対応したローカル版が必要です。

この説明書の使い方

  • 初めてお使いの場合は、第1章「基本操作」に沿って、読み込みから保存まで進めてください。
  • 操作を調べる場合は、目次から各章へ移動してください。保存方法、ショートカット、トラブル対処は一覧から確認できます。
  • 「 」は画面上のボタン・項目名を示します。Ctrlなどの囲みは、キーボードのキーを示します。

編集画面の上部にある青色の「マニュアル」を選択すると、編集中の画面を残したまま、新しいタブでこの説明書を開けます。

上部の「ダーク」「ライト」で表示を切り替えられます。初回はダーク表示になり、選択した設定は同じブラウザに保存されます。印刷時は白背景になります。

01基本操作

1枚の画像にセリフを配置し、PNGと再編集用データを保存するまでの手順を説明します。

操作手順

  1. 画像を開きます上部の「画像を追加」で画像を選択してください。フォルダ単位で読み込む場合は「フォルダを開く」を選択してください。手元の画像を使わずに試す場合は、「3枚のサンプルで試す ↗」をご利用ください。
  2. セリフを入力します画像の中央列で「＋ 男性」または「＋ 女性」を押し、カードの本文欄に入力してください。新しいセリフは縦書きで追加されます。話者はカードの見出しで切り替えられます。
  3. 位置と大きさを整えます右のプレビューで文字をドラッグしてください。選択枠の右下でサイズ、上の丸で回転を調整できます。書体・文字サイズ・文字方向は、下の設定欄で変更してください。
  4. 画像と編集データを保存します「画像を保存」を押すと、この1枚をPNGで出力できます。あとで編集し直す場合に備えて、上部の「編集データを保存」から.serifuファイルも保存してください。

複数枚をまとめて保存する場合は、「一括保存」をご利用ください。PNGと再編集用データを、新しいフォルダまたはZIPにまとめて保存できます。詳しくは保存方法の違いをご確認ください。

02画面の見方

各画像の編集画面は3列で構成されています。下へスクロールすると、次の画像を続けて編集できます。狭い画面では、各列が縦に並びます。

01 / ORIGINAL元画像

元の画像を確認できます。画像の除外・複製と、SAM3によるマスク検出を行います。

02 / WORDSセリフ・効果音

オブジェクトを追加し、本文・色・装飾・プリセットを編集します。

03 / LIVE PREVIEW仕上がり・配置

ドラッグで位置を調整できます。数値設定、クロップ、回転、PNG保存も行えます。

上部のメニューには、読み込み・保存・既定プリセット・自動保存の項目があります。左の「ページ一覧」では、サムネイルからの移動と絞り込みができます。中央のカードやプレビューを選択すると、そのオブジェクトの設定が開きます。

ライブプレビューでセリフ・吹き出し・キャプション・効果音を選択し、Enterを押すと、その本文欄へ移って末尾から入力できます。複数選択中は、最後に選択した対象の本文欄へ移ります。入力欄でのEnterは、通常どおり改行になります。

細部を確認する

  • 100%：原寸プレビューを別画面で表示します。10〜200%に拡縮でき、ドラッグで表示位置を移動できます。「閉じる」またはEscで元の画面に戻ります。
  • ライブプレビューのFOCUS：枠の大きさを固定して、拡大しながら編集できます。倍率100%では、元画像の1pxを画面の1pxで表示します。倍率欄への数値入力または上下ドラッグで倍率を変更し、手のひらボタンで表示位置を移動してください。元画像側のFOCUSについては、SAM3のポイント指定とFOCUSをご確認ください。
  • 拡大鏡ボタン：画像の一部を等倍で確認できます。拡大鏡の位置とサイズは、ドラッグで調整してください。

03画像とページの管理

「画像を追加」では複数の画像を選択できます。「フォルダを開く」では、フォルダ内の画像を読み込みます。画像ファイルをページ一覧にドロップしても追加できます。新しく読み込んだ画像は、ファイル名の数字を考慮した順序で並びます。

ページ一覧と各画像の見出しで使う操作
操作使い方
ページの移動サムネイルをクリックするか、上部の矢印・画像選択欄で移動してください。
画像の複数選択最初のサムネイルをクリックし、Shiftを押しながら別のサムネイルをクリックすると、その間に表示されている画像をまとめて選択できます。Ctrl（Macでは⌘）＋クリックでは、画像を個別に追加・解除できます。選択中の画像は枠で強調され、選択枚数が表示されます。通常のクリックやページ移動では1枚の選択に戻り、フィルターを切り替えると複数選択は解除されます。
絞り込み「未編集のみ」「編集済みのみ」「未確認のみ」「確認済みのみ」から選択してください。「すべて」を選択すると解除できます。
並べ替えサムネイルをドラッグするか、フォーカスした状態でAlt＋↑／↓を押してください。画像見出しの「ページ移動↑／↓」も使えます。「ページの後へ」に現在のページ番号を入力して「移動」を押すと、そのページの直後へ移動します。0を指定すると先頭へ移動します。
確認済みにする「編集完了・次へ」を押すと、確認済みにして次へ進みます。確認済みと編集済みは別の状態です。
表示を軽くする表示件数を「50件ずつ」または「100件ずつ」に設定してください。表示範囲やフィルターを変更しても、一括保存の対象は表示中の範囲だけには限定されません。
一覧の大きさサムネイル倍率は50〜200%で調整できます。一覧の右端をドラッグすると幅を変更でき、ダブルクリックすると初期幅に戻ります。「サムネイルを非表示」で一覧を隠せます。
画像複製元画像だけを一覧内に複製します。文字などの編集内容は引き継ぎません。
一覧から外す各画像の「一覧から外す」で除外できます。複数画像をまとめて外す場合は、サムネイルで選択し、サムネイルにフォーカスがある状態でDeleteを押してください。確認画面の枚数・ファイル名を確認して「はい」を押すと実行され、「いいえ」またはEscで中止できます。元ファイルは残りますが、対象画像の未保存の編集は失われます。一覧から外す操作はUndoでは戻せません。

注意：「元画像を削除」では、実ファイルが完全に削除されます。ファイル名を確認してから実行してください。ゴミ箱には移動せず、Undoでも元に戻せません。「フォルダを開く」で直接接続し、削除APIを利用できる画像だけが対象です。画像追加・サンプル・編集データから読み込んだ画像では使えません。

画像別のJSON下書きを取り込む

同じフォルダにimg001.jpgとimg001.jpg.jsonを置き、「フォルダを開く」で読み込んでください。通常の画像追加やドラッグ追加では、下書きは取り込まれません。

{
  "schemaVersion": 1,
  "imageFile": "img001.jpg",
  "annotations": [
    { "type": "dialogue", "speaker": "female", "text": "こんにちは" },
    { "type": "speech_bubble", "text": "吹き出しの本文" },
    { "type": "caption", "text": "その日のこと。" },
    { "type": "sound_effect", "text": "ドン" }
  ]
}

セリフのspeakerには、maleまたはfemaleを指定してください。既定のプリセットを使い、右上から左へ、その後は下段へ自動で配置されます。収まらない場合は縮小され、縮小の限界を超えた分は画像外に残して警告を表示します。保存前に位置とサイズをご確認ください。

不正な下書きがあっても、画像は読み込まれます。元画像・下書きJSONは変更されません。この形式は、「編集データを追加」で開くプロジェクト形式とは異なります。

04セリフと文字の書式

「＋ 男性」「＋ 女性」でセリフを追加できます。初期色は男性が黒、女性がピンクで、輪郭は白です。色と輪郭は変更できます。セリフを追加しても、吹き出しは自動では付きません。

  • 本文欄に直接入力してください。入力欄の高さは入力した改行に合わせて伸び、長い1行は横にスクロールできます。プレビューでの折り返しは、配置幅・高さにも依存します。
  • カード見出しの「男性」「女性」で話者を変更できます。「文字色」「文字の輪郭色」「文字の輪郭の太さ」で見た目を調整してください。輪郭の太さを0にすると、輪郭を消せます。
  • 「文字方向」で縦書き／横書きを選択してください。縦書きの句読点は、文字枠の右上に配置されます。「改行位置」の上付き／中央揃えで、複数行の揃え方を変更できます。
  • 「文字の太さ（px）」は−10〜30で指定できます。0が書体の標準で、正の値では太く、負の値では細くなります。輪郭や文字サイズとは別の設定です。細くしすぎると細い線が消えるため、プレビューで確認しながら調整してください。

書体を選ぶ

右側の「書体」から、ゴシック・明朝・手書き・漫画向けなどの書体を選択してください。選択した書体の読み込みが終わると、プレビューが更新されます。PNG保存も書体の読み込み完了を待って実行されます。書体に含まれない文字は、端末の代替書体で表示されます。

「激筆 SFX」はかな・英大文字・数字・記号向けで、漢字と英小文字は代替書体になります。「851チカラヨワク」は「手書き・丸文字」から選択できます。ローカル環境で書体が見つからない場合は、困ったときはの準備方法をご確認ください。

書体の種類と同梱ライセンス

同梱の19書体と、端末のゴシック・明朝を選択できます。漫画向けには激筆 SFX・Dela Gothic One・Reggae One、筆文字にはYuji Boku・Yuji Mai・Yuji Syuku、手書きにはKlee One・Yomogi・851チカラヨワクなどを用意しています。

Google Fonts由来の17書体には、それぞれのOFLライセンスを同梱しています。激筆 SFXはHIDEOUT作で、CC0 1.0が適用されます。851チカラヨワクは8:51:22 pm作で、作者の規約に従ってご利用ください。フォントを準備・ビルドした環境では、assets/fonts/に各ライセンス・規約が収録されます。

05吹き出し

「○ 吹き出し」で追加できます。本文は同じカードに入力でき、空欄のまま背景だけにも使えます。話者・書体・文字色も変更できます。初期状態は白・25%透過（不透明度75%）・黒枠で、テールは付いていません。

  1. 右の「吹き出し形状」で、楕円・歪み長方形・尖り形・多角形などを選択してください。形状を変更しても、位置・大きさ・本文は保持されます。
  2. 多角形の頂点数は3〜60で指定できます。「頂点数をランダム生成」で別の頂点数に変更できます。歪み度を0%にすると、均等な多角形になります。「形状を再生成」では、同じ頂点数で形を変更できます。
  3. 塗り色・透過率・枠線色・枠線の太さを調整してください。枠線の太さを0にすると、枠を消せます。「影を付ける」では、影の色・濃さ・ぼかし・ずれを指定できます。「枠線の描き方」でブラシ風を選ぶと、ラフな縁取りにできます。
  4. 「テールを追加」をオンにすると、水色の先端をドラッグできます。先端の座標・付根の角度・幅は、数値でも調整できます。
  5. 本文だけを移動する場合は、「文字の横位置」「文字の縦位置」を使ってください。正の値を指定すると、横位置は右へ、縦位置は下へ移動します。「内側の余白」では、折り返しまでの長さを調整できます。

吹き出しの本文は、枠の外側にも表示されます。ただし、画像の外側はPNGに出力されません。枠内に収めたい場合は、文字位置・余白・文字サイズを調整してください。

06キャプション

「▭ キャプション」で、モノローグや説明用の長方形ボックスを追加できます。本文とボックスを一つのオブジェクトとして移動できます。初期状態は白背景・25%透過・黒枠・黒文字・縦書きで、本文は左右上下とも中央揃えになります。

  • カードで本文・文字色・文字の輪郭・背景色・背景の透過率・枠線を編集してください。右側では、書体・文字方向・位置・ボックスの寸法・回転を調整できます。
  • 「左右の揃え方」「上下の揃え方」で位置を指定してください。「文字の横位置」「文字の縦位置」では、ボックスを動かさずに本文だけをずらせます。
  • 「文字サイズをボックスに合わせる」は、初期状態ではオフです。オフの場合は、ボックスのサイズを変更しても、手動で指定した文字サイズが保持されます。本文はボックス内で折り返され、はみ出した部分は切り取られます。
  • オンにすると、本文・書体・方向・余白・枠線に合わせて、収まる文字サイズが自動計算されます。オフに戻すと、手動の文字サイズに戻ります。最小サイズでも収まらない場合は、ボックスを広げるか、本文・余白を減らしてください。

07効果音・文字単位編集

「✦ 効果音」で追加し、本文と書体を選択してください。まずプリセットで近い表現を選び、必要な項目を調整すると作りやすくなります。

設定表現と調整
漫画エフェクト立体・集中線・スピード・震え・先細りなどを選択できます。「なし」を選ぶと漫画装飾が外れますが、別に指定したブラー・掠れ・歪みは残ります。
先細り入力順に文字が小さくなります。基準100px・変化率10%の場合は、100→90→80pxと変化し、最小8pxまで縮小されます。改行後も順番は続きます。
ばらつき文字サイズのばらつきと左右のズレを調整できます。0を指定すると、追加のばらつきがなくなります。保存・再読み込みによって模様が変わることはありません。
ブラー・筆表現縦横のブラー、滲み、文字の芯、輪郭の荒れ、筆の掠れ、ハネ・払い、残像、傾き、縦横倍率を組み合わせて調整してください。
かすれ印刷「インク質感」の「かすれ印刷・荒れインク」を選択し、強さ・擦れ筋の長さと方向・飛沫量を調整してください。欠けた部分は透明になります。「模様を再生成」で模様を変更できます。

1文字ずつ形を整える

  1. 効果音カードで「文字単位編集」を押してください。
  2. 文字を選択し、移動・回転・倍率・傾き・書体・色・輪郭を調整してください。Shiftで複数選択でき、Altで重なった背面の文字を選択できます。
  3. 詳細パネルでは、矩形／なげなわ選択、共通中心での一括変形、位置・変形・外観ごとのリセット、4案の配置比較を利用できます。
  4. 選択した文字は、Ctrl／⌘＋C・V・Dやドラッグでコピー・複製できます。別の効果音へ貼り付けた場合は、貼り付け先の外観が使われ、本文も更新されます。
  5. 「文字編集を終了」を押すか、入力欄の外でEscを押すと、通常の編集に戻ります。
長音の曲線・テンプレート・本文の変更

連続する「ー」は、編集開始後に曲線として調整できます。曲線点・太さ点をドラッグし、点の追加削除、端点の接続／分離、長さロック、端の形状、線幅の補間を指定してください。形状・太さ・見た目だけの部分コピーも使えます。単独の「ー」は、通常の文字として扱われます。

合成外周は重なりに応じて生成され、メンバーを手動で固定できます。テンプレートはブラウザ・プロジェクト・JSONで管理できます。本文とページ上の絶対位置を変えずに、文字数が異なる効果音にも適用できます。

文字単位編集を始めた効果音の本文を変更する場合は、位置／文字一致／リセットから継承方法を選択してください。本文欄でEscを押すと変更を取り消せます。Ctrl／⌘＋Enterを押すか、別の場所へフォーカスを移すと確定します。

不足する書体は、代替書体を選ぶか、アップロードして補えます。アップロードした書体は現在のセッション内だけで有効で、編集データにはファイルが同梱されません。再開時には、同じ書体を用意してください。

タッチ操作では、大型ハンドル・長押しルーペ・2本指ズーム／パンを利用できます。操作感は端末によって異なります。画像外の文字・線には警告が表示されます。これらは編集データには残りますが、PNGでは画像端で切り取られます。

08配置・複製・重なり

プレビューで対象を選択し、ドラッグで移動してください。Shiftを押しながら選ぶと、複数選択できます。右下の角でサイズ、上の丸で回転を調整できます。X/Y・配置幅・配置高さ・回転は、数値でも指定できます。

コピーと複製

  • 選択した対象：Ctrl／⌘＋Cでコピーし、貼り付け先のプレビューを選択してから、Ctrl／⌘＋Vで貼り付けてください。書式と配置は保持され、解像度が異なる画像では拡縮されます。貼り付けるたびに、位置が少しずつずれます。
  • ドラッグ複製：Ctrl／⌘を押しながらドラッグしてください。さらにShiftを押すと、元の対象を通る水平・垂直ガイドに沿って移動できます。クリックしただけでは複製されません。
  • 画像内の文字をまとめてコピーする場合：「文字を一括コピー／カット」を押し、貼り付け先で「文字を一括ペースト」を押してください。セリフ・効果音・吹き出し・キャプションが対象で、マスクは含まれません。貼り付けた内容は、既存の文字に追加されます。
  • 次の画像へ複製する場合：「文字を次の画像へ複製 →」を押すと、次の画像のサイズに合わせて文字が追加されます。

コピーした内容は、同じタブ内で再読み込みするまで保持されます。元の内容をあとで変更してもコピーは変わらず、繰り返し貼り付けられます。縦横比が異なる画像では折り返しや収まりが変わるため、貼り付け後に確認してください。

前後関係と取り消し

右の「背面へ／前面へ／最背面へ／最前面へ」で重なりを変更できます。マスク・文字・吹き出しは共通の順序で扱われ、一覧では上が背面、下が前面になります。前面のマスクは文字も覆います。

「戻す」「↷」で、画像ごとの編集を取り消し・やり直しできます。複製や一括貼り付けは、1回の操作として取り消されます。カットと貼り付けを元に戻す場合は、それぞれの操作を行った画像で取り消してください。

09プリセット

  1. セリフ・効果音・吹き出し・キャプションを選択し、書式と配置を整えてください。
  2. カードの「保存」または上部の「選択中の設定を記憶」で、名前を付けて保存してください。
  3. カードの選択欄からプリセットを適用してください。上部の種類別の「既定」で選択すると、新しく追加する対象にも適用できます。

プリセットには書式と配置が保存されます。本文・話者は保存されません。画像の解像度が異なる場合は、配置や文字サイズが拡縮されます。同じ種類・同じ名前で保存する場合は、確認後に上書きされます。

ユーザープリセットを削除する場合は、カードのプリセット欄にある「削除」か、上部の既定選択の右にある「×」を押してください。配置済みの見た目は保持され、組み込みプリセットは削除できません。プリセットは同じブラウザに保存され、編集データにも含まれます。

10画像加工・SAM3

クロップと回転

プレビュー上部の「クロップ」を押し、ドラッグで範囲を選択してから「適用」を押してください。枠内をドラッグすると範囲を移動でき、辺や角でサイズを調整できます。X/Y・幅・高さは、回転後の元画像のピクセル数で指定してください。「左回転」「右回転」では、画像全体を90度ずつ回転できます。

「クロップ・回転をリセット」を押すと、元の範囲と向きに戻せます。元ファイルは上書きされません。PNGは、クロップ・回転後の解像度で保存されます。

SAM3で領域を指定する

SAM3の新規検出には、GPUに対応したローカル環境での起動が必要です。通常の編集はブラウザ内で行われますが、SAM3では元画像をお使いのローカル推論サーバーに送信して処理します。公開版では新規検出を利用できません。保存済みのマスクは編集・出力できます。

  1. 元画像の下にあるSAM3カードでテキストを入力し、「検出」を押してください。Enterでも検出できます。日本語変換の確定中は実行されません。
  2. 必要に応じて、前景・背景ポイントで領域を指定してください。番号・色・信頼度を確認しながら候補を選択してください。複数の候補も選択できます。
  3. 加工方法を選び、プレビューで確認してから「選択候補を加工に追加」で確定してください。入力を変更した場合は、最新の検出結果が届くまでお待ちください。確定前の仮加工は、PNG・編集データには保存されません。
  4. 確定したマスクのカードで、ピクセレート・ぼかし・黒塗り・白塗り、輪郭補正、表示、X/Y/W/Hを変更できます。プレビューでは、移動と8方向のサイズ調整ができます。

SAM3のポイント指定とFOCUS

  1. SAM3パネルの「＋ 前景点」または「− 背景点」を選択してください。元画像上のクリックで点を追加でき、前景点が1つ以上あると検出が実行されます。背景点だけでは検出できません。
  2. 元画像上部の「FOCUS」は初期状態でオンです。マウスカーソルを元画像に重ねて少し止めると、カーソルに対応する元画像の位置を基準に100%表示へ切り替わります。表示枠の大きさは変わらず、その後はマウスの動きに追従します。
  3. 拡大中も、その位置をクリックして前景点・背景点を追加できます。カーソルを画像の表示枠から離すと、全体表示へ戻ります。全体表示のまま点を置きたい場合は、「FOCUS」をオフにしてください。

このFOCUSは元画像でのポイント指定用です。「候補選択」中やタッチ操作では自動拡大しません。FOCUSの切替やマウス移動だけで検出は実行されません。「候補選択」へ切り替えるか「キャンセル」を押すと全体表示へ戻り、FOCUSのオン／オフ設定は維持されます。ライブプレビュー側のFOCUSとは、別々に操作できます。

新規検出の対象はPNG・JPEG・WebPで、30MiB以下かつ40Mpx以下の画像です。GIF・AVIF・アニメーション画像の推論には対応していません。モデルやサーバーの準備については、READMEの起動手順をご確認ください。

ピクセレート・ぼかしは匿名化を保証するものではありません。マスクを確定したあとに、保存した画像もご確認ください。マスク素材は編集データに含まれるため、復元後は推論サーバーなしでも再編集できます。

11書き出しと再編集

目的に合わせて保存方法を選んでください。
操作保存するもの
画像を保存その画像だけを合成済みPNGとして保存します。選択枠は含まれません。保存先はブラウザのダウンロード設定に従います。再編集用データは、別途保存してください。
一括保存全画像のPNGと編集データを保存します。選択した親フォルダの中に、日時・ID付きの新しいフォルダが作成されます。フォルダ保存に対応していない場合は、ZIPをダウンロードします。
編集済み画像一括保存文字などを編集した画像だけを、PNGと編集データに保存します。画像を開いた・選択した・確認済みにしただけのページは、対象に含まれません。
編集データを保存画像・文字・マスク・配置・プリセットなどを1ファイルにまとめます。初期形式の.serifuをおすすめします。上部の「保存形式」でJSONも選択できます。
テキストを保存女性／男性／全台詞／キャプション／効果音／全本文から選択し、全ページを現在の順序でTXTとして保存します。台詞は1件ごとに「」で囲まれ、空の本文は省かれます。

一括保存したPNGには、p01_元の名前.pngのように、ページ順の番号が付きます。桁数は全体の枚数に合わせられ、編集済みの画像だけを保存する場合も全体の番号が保持されます。PNGは画像の解像度を保ち、クロップ・回転を行った場合は、その結果の寸法になります。

保存した編集を再開する

  • 「プロジェクトを開く」：現在の一覧を、保存ファイルの内容に置き換えます。現在の作業を残したい場合は、先に編集データを保存してください。
  • 「編集データを追加」：保存ファイルの画像と編集内容を、現在の一覧に追加します。
  • 同じプロジェクトでファイルと自動保存の内容が異なる場合は、ファイル・自動保存・別プロジェクトのどれで開くかを選択してください。

PNGだけでは、文字や吹き出しを個別に再編集できません。保管や端末の移行に備えて、.serifuファイルも残してください。旧形式の編集データは読み込めますが、新しい形式のデータは古いアプリでは開かないでください。JSONに切り替えても、旧版向けの形式には変換されません。

一括処理を中断する

上部の進捗欄で、処理段階・件数・失敗・経過時間を確認できます。「中断」を押すと、残りの処理を停止します。画像追加を中断した場合は追加済みの画像が残り、フォルダ保存を中断した場合は出力済みのファイルが残ります。ZIPはダウンロード開始前であれば中断できます。通常のダウンロードは、開始後にアプリから取り消すことはできません。

注意：保存の失敗や中断が発生した場合は、画面下部の結果と保存済み枚数をご確認ください。フォルダには途中までの出力が残ります。元画像は上書きされません。

12一時保存と復元

「一時保存」では、画像と編集内容をブラウザ内に保存します。自動保存は初期状態でオンになっています。編集を確定すると最新状態が保存され、設定した周期でも確認されます。変更がある場合は、復元用の履歴が原則5分間隔で、最大5世代まで保存されます。

  1. 再読み込みしたあとに、「保存した編集を復元」で作業を再開してください。
  2. 「保存プロジェクト管理」では、プロジェクトと世代を選択して復元・削除できます。保存容量も確認できます。
  3. 「一時保存を消去」では、対象プロジェクトの最新状態だけが削除されます。履歴や別のプロジェクトは残ります。

同じプロジェクトを編集できるのは1つのタブだけで、ほかのタブは閲覧専用になります。編集タブを閉じたあとなどは、閲覧タブで操作すると、最新状態が再読み込みされて編集を引き継げます。別のプロジェクトは、それぞれ独立して保存されます。

一時保存は、同じブラウザ・同じサイト内に保存されます。サイトデータを削除すると失われます。公開版とローカル版、ポートが異なるローカル版では、保存先が別になります。環境を移行する場合は、編集データをファイルに保存して持ち出してください。容量不足で自動保存が停止した場合は、ファイルに退避して保存領域を整理し、手動での保存が成功することをご確認ください。

14困ったときは

フォルダへ直接保存できない

フォルダへの直接保存と元画像の削除には、対応ブラウザのFile System Access APIが必要です。PC版Chrome／Edgeで、localhostまたはHTTPSからご利用ください。非対応の環境では、一括保存はZIP、単体保存は通常のダウンロードになります。ZIPは全体で4GiB未満、最大65,535ファイルまで対応しています。大きな作業は分割して進めてください。

文字が見切れる・小さくなった

文字サイズ・配置幅・配置高さ・余白をご確認ください。キャプションの自動追従がオンになっている場合は、ボックスに合わせて文字が縮小されます。吹き出しの本文は枠外にも表示されますが、キャプションの本文は枠内で切り取られます。画像外の部分は、どちらもPNGには含まれません。

想定した書体にならない

書体の読み込み状態と、その書体に使いたい文字が含まれているかをご確認ください。ローカルで同梱書体が見つからない場合は、リポジトリのルートでnpm run fontsを実行してから再読み込みしてください。アップロードした書体は、再起動時に再度用意してください。端末の代替書体は、環境によって見た目が異なります。

編集済みだけ保存すると画像が抜ける

確認済みと編集済みは、別の状態です。画像の読み込み・選択・「編集完了・次へ」だけでは、編集済みにはなりません。最初の編集をUndoで取り消すと、未編集に戻ります。文字を削除した結果、元画像だけに見えるページも、編集済みとして扱われる場合があります。全画像を保存したい場合は、「一括保存」をご利用ください。

一時保存が見つからない

保存したときと同じブラウザ・サイト・ポートで開いているかをご確認ください。別の環境に移す場合は、.serifuファイルを移して「プロジェクトを開く」で読み込んでください。復元した画像は元フォルダへの接続を持たないため、「元画像を削除」は利用できません。

SAM3で検出できない

公開版やnpm startだけで起動した環境では、新規検出は利用できません。READMEのGPUセットアップを済ませ、npm run devで起動してください。モデルの場所、入力形式と画像サイズ、カードに表示されるエラーをご確認ください。

動作が重い・出力が途中で止まる

表示件数を減らし、大量の画像や高解像度の画像は分けて編集してください。強いブラーや極端な拡大も負荷が増える原因になります。保存途中で止まった場合は、結果表示と出力済みファイルをご確認ください。PNGは静止画として出力され、GIFの動きやEXIFなどの元画像のメタデータは引き継がれません。高度な縦組み約物・ルビには対応していません。
